Why I wrote this guide

Many AI users are looking for free models that don't compromise too much on quality. Agnes fits that need well — it's genuinely free, and the results are good enough for most routine tasks. The only real downside is the response speed. This guide walks through exactly how to configure it in WorkBuddy, so you can start using it without hitting common pitfalls.

Key point: Agnes is designed as an API-accessible AI service — you can use it programmatically via API calls, not just through a web interface. This makes it especially useful for developers and users who want to integrate the model into their own workflows or applications, at zero cost.

Step 1: Register on Agnes and get your API Key

Start by visiting the Agnes platform and signing in. You can register with an email account or quickly sign in with Google / GitHub:

👉 Agnes 官网 / Sign-up page
https://platform.agnes-ai.com/login

The login page supports email registration, plus one-tap sign-in via Google and GitHub:

Once you're signed in, open the 设置 → API 密钥 (Settings → API Keys) section in the left sidebar:

Click the black "创建新的密钥" (Create new key) button. A small modal pops up asking for a name:

Give it any name you like — the name doesn't matter functionally. You can use something like workbuddy, my-laptop, or tan-home. Pick whatever helps you remember where you used this key. Then hit 保存 (Save).

Agnes will show the generated key once, masked in the middle, with a copy icon on the right. Copy it immediately and store it somewhere safe (password manager / encrypted note):

⚠️ Critical: The full key is shown only at this moment. If you close the modal without copying, you'll have to delete the old one and generate a new key. Don't paste it into public chats or commit it to a public repo — treat it like a password.

Recap of Step 1: visit platform.agnes-ai.com/login → sign in → Settings → API Keys → create new key (any name) → save → copy the key.

Step 2: Configure the custom model in WorkBuddy

Log in to your WorkBuddy account and navigate to the custom model configuration page. Here's what you need to fill in:

  • Model Name: agnes-2.0-flash — this is critical. It must be spelled exactly as shown, case-sensitive. If you type it wrong (e.g., agnes-2.0-flashx, Agnes-2.0-Flash, or any variation), the configuration will not work.
  • API Base URL: Enter the Agnes API endpoint provided on their platform.
  • API Key: Paste the key you copied from Step 1.
  • Other fields: Fill in any required parameters (e.g., max tokens, temperature) according to Agnes's documentation. Start with default values if you're unsure.

What to expect

✅ Pros:
  • Free API access: No subscription fees, no pay-per-use costs. You can use Agnes via API calls completely free — ideal for automation, custom integrations, and programmatic use.
  • Usable quality: For most everyday writing, summarization, and Q&A tasks, Agnes delivers solid results that are good enough for practical use.
  • Easy to configure: WorkBuddy's interface is straightforward, and the setup process takes only a few minutes.
⚠️ The catch: Agnes is slightly slower compared to premium models like GPT-4 or Claude. Response times are acceptable but may feel a bit laggy for real-time conversations or large context inputs. If speed is your top priority, this is a factor to weigh.

Common mistakes to avoid

  • Wrong model name: As emphasized, agnes-2.0-flash must be exact. Even a single extra character or wrong case will cause the configuration to fail.
  • Expired API key: If you regenerate a key, remember to update it in WorkBuddy. Old keys will stop working.
  • Missing required fields: Double-check all mandatory fields in WorkBuddy's configuration form before saving.

Testing your configuration

After saving the configuration, run a quick test prompt to verify everything works. Try a simple query like "Summarize this article" or "What's the capital of France?" If you get a reasonable response within a few seconds, your setup is successful. If you encounter errors, re-check the model name and API key first — these are the most common culprits.
