Configuring Agnes in WorkBuddy: A Free Agent Model (Slightly Slower, Fully Usable) — Hands-on Guide

By Tan Haosheng · 副主任医师 / 医学博士 (Associate Chief Physician, MD/PhD) · 甲状腺乳腺外科 (Thyroid & Breast Surgery), 泰州市人民医院 (Taizhou People's Hospital) · Last updated 2026-07-29
🛠️ Workflow #1 / 3 · Configuration Guide 1 of 3
The short answer: Agnes offers a free API-accessible model that's genuinely usable for day-to-day tasks, with a caveat — it's slightly slower than paid alternatives. If you're on a budget or want to experiment without spending money, Agnes is a solid choice. The key is getting the configuration right in WorkBuddy, especially the model name.

Why I wrote this guide

Many AI users are looking for free models that don't compromise too much on quality. Agnes fits that need well — it's genuinely free, and the results are good enough for most routine tasks. The only real downside is the response speed. This guide walks through exactly how to configure it in WorkBuddy, so you can start using it without hitting common pitfalls.

Key point: Agnes is designed as an API-accessible AI service — you can use it programmatically via API calls, not just through a web interface. This makes it especially useful for developers and users who want to integrate the model into their own workflows or applications, at zero cost.

📋 Before you start

This guide adds Agnes inside WorkBuddy, so you'll need WorkBuddy installed and signed in first. It's free:

⬇️ Download WorkBuddy → workbuddy.cn

Step 1: Register on Agnes and get your API Key

Start by visiting the Agnes platform and signing in. You can register with an email account or quickly sign in with Google / GitHub:

👉 Agnes 官网 / Sign-up page
https://platform.agnes-ai.com/login

The login page supports email registration, plus one-tap sign-in via Google and GitHub:

Once you're signed in, open the 设置 → API 密钥 (Settings → API Keys) section in the left sidebar:

Click the black "创建新的密钥" (Create new key) button. A small modal pops up asking for a name:

Give it any name you like — the name doesn't matter functionally. You can use something like workbuddy, my-laptop, or tan-home. Pick whatever helps you remember where you used this key. Then hit 保存 (Save).

Agnes will show the generated key once, masked in the middle, with a copy icon on the right. Copy it immediately and store it somewhere safe (password manager / encrypted note):

⚠️ Critical: The full key is shown only at this moment. If you close the modal without copying, you'll have to delete the old one and generate a new key. Don't paste it into public chats or commit it to a public repo — treat it like a password.

Recap of Step 1: visit platform.agnes-ai.com/login → sign in → Settings → API Keys → create new key (any name) → save → copy the key.

What the API key is for — and the easiest way to use it

With the API key in hand, you now have two ways to drive Agnes:

  • Call the API directly — you can hit the endpoint from a terminal or your own script (e.g. curl / Python / a bash shell). This is fully doable and gives you raw programmatic control over every request.
  • Let the agent use it for you — this is the part that makes Agnes genuinely pleasant to work with. Once configured in WorkBuddy (Steps 2–3), you simply open a chat, pick agnes-2.0-flash, and the agent handles the API calls, tool use, and multi-turn reasoning behind the scenes.
💡 The takeaway: Yes, you can call the Agnes API from bash or any terminal. But for day-to-day work — writing, research, coding, multi-step tasks — the agent is by far the most convenient front-end. You get all the benefits of the free API without writing a single line of integration code.

Step 2: Configure the custom model in WorkBuddy

Log in to WorkBuddy, then click the Auto selector in the bottom-right corner of the chat input box. The whole configuration goes through 5 small clicks:

A dropdown appears. Scroll to the very bottom and click Configure custom models:

The Add Model dialog opens. Notice the badge at the top: OpenAI-compatible API required. The default Provider is the Tencent Cloud Token Plan, but Agnes isn't in the built-in list — so we have to scroll the Provider dropdown all the way down to pick Custom:

In the Provider dropdown, scroll past all the built-in options (Kimi Coding Plan / GLM / Kimi China / MiniMax China / DeepSeek / Ollama …). At the very bottom of the Other section, pick Custom:

Important: do not pick anything that looks similar (e.g., "GLM Open Platform", "MiniMax China") just to save a step — only Custom lets you type your own Endpoint + Model Name. Everything else locks you to that vendor's preset model list.

Once you pick Custom, the full form appears. Fill in three required fields exactly as shown:

  • Provider: Custom (already chosen above)
  • Endpoint: https://apihub.agnes-ai.com/v1 — this is Agnes's OpenAI-compatible base URL. Copy it character-for-character, including the trailing /v1.
  • API Key: paste the key you copied in Step 1 (the one that begins with sk-).
  • Model Name: agnes-2.0-flash — critical. It must be spelled exactly as shown, case-sensitive. If you type it wrong (e.g., agnes-2.0-flashx, Agnes-2.0-Flash, AGNES-2.0-FLASH, agnes-2-flash, or anything else), the API call will return an error and the model will not respond.
🌏 Mainland China users: If you are in mainland China, use the domestic mirror endpoint instead — https://apihub.agnes-ai.cn/v1/chat/completions. The default .com/v1 endpoint will throw a connection/timeout error from inside China. Use the .cn URL exactly as shown, including the full /v1/chat/completions suffix.
⚠️ The three landmines for Model Name:
  1. Wrong case — every character is lowercase + digits + dots + dashes. There is no uppercase letter in the correct name.
  2. Missing the .0 — common typo is agnes-2-flash. The dot-zero between 2 and flash must be there.
  3. Adding an extra suffix — e.g., agnes-2.0-flashx, agnes-2.0-flash-v2. Don't improvise; copy the exact string above.
Quick reference card — copy this block: 
Provider : Custom
Endpoint : https://apihub.agnes-ai.com/v1          (mainland China: https://apihub.agnes-ai.cn/v1/chat/completions)
API Key  : sk-... (paste from Step 1)
Model    : agnes-2.0-flash   <-- exact, case-sensitive

Advanced Settings (Tool Calling / Image Input / Reasoning / Custom Protocol) — leave these at default unless you specifically need them. Token context windows can also stay at default. Hit Save, and you're done.

Step 2 recap: Auto → Configure custom models → Add Model → Provider = Custom → fill in Endpoint / API Key / Model Name (agnes-2.0-flash) → Save.

Step 3: Verify and use it

Now that the custom model is saved, go back to the main chat window. Click the model selector (the Auto button at the bottom-right of the input area) again. This time, scroll to the very bottom of the dropdown — under a group called Custom Models — and you'll see agnes-2.0-flash with a green check mark next to it, meaning it's active.

💡 Daily use tip: Once configured, you don't need to revisit the custom-models page. Just open any chat and pick agnes-2.0-flash from the bottom of the model list. To switch back to another model later, click the same selector and choose a different one.
🛠️ Ultimate Weapon (终极武器): Automatic configuration by WorkBuddy AI
If you can't configure it manually, try this: In WorkBuddy, select a model like Kimi K3 (or another capable model) and paste this prompt directly:

I can't configure the model myself. Help me set it up completely. Here are the details:
• Model name: agnes-2.0-flash
• API Base URL: https://apihub.agnes-ai.com/v1 (if you are in mainland China, use https://apihub.agnes-ai.cn/v1/chat/completions instead)
• API Key: [your-key-here]

Please configure this for me completely — I don't need to handle any details.

Most of the time, WorkBuddy's AI agent can successfully configure the model or fix any bugs/unstable situations. This is a fail-safe option when manual configuration fails.
🔑 Key benefit — works even at 0 credits: Once Agnes is configured, you can use it to do real tasks inside WorkBuddy even when your WorkBuddy account balance is 0. Because Agnes is called through its own free API key, it does not consume WorkBuddy's built-in credits. In other words: the moment setup succeeds, you get a working model for everyday jobs regardless of your remaining quota.

What to expect

✅ Pros:
  • Free API access: No subscription fees, no pay-per-use costs. You can use Agnes via API calls completely free — ideal for automation, custom integrations, and programmatic use.
  • Usable quality: For most everyday writing, summarization, and Q&A tasks, Agnes delivers solid results that are good enough for practical use.
  • Easy to configure: WorkBuddy's interface is straightforward, and the setup process takes only a few minutes.
⚠️ The catch: Agnes is slightly slower compared to premium models like GPT-4 or Claude. Response times are acceptable but may feel a bit laggy for real-time conversations or large context inputs. If speed is your top priority, this is a factor to weigh.

Common mistakes to avoid

  • Wrong model name: As emphasized, agnes-2.0-flash must be exact. Even a single extra character or wrong case will cause the configuration to fail.
  • Expired API key: If you regenerate a key, remember to update it in WorkBuddy. Old keys will stop working.
  • Missing required fields: Double-check all mandatory fields in WorkBuddy's configuration form before saving.

Testing your configuration

After saving the configuration, run a quick test prompt to verify everything works. Try a simple query like "Summarize this article" or "What's the capital of France?" If you get a reasonable response within a few seconds, your setup is successful. If you encounter errors, re-check the model name and API key first — these are the most common culprits.

Verdict

Agnes is a genuinely free model that delivers usable results. If you're looking for a no-cost option for WorkBuddy and can tolerate slightly slower response times, Agnes-2.0-flash is worth configuring. Just remember: the model name must be exactly agnes-2.0-flash — misspell it and nothing will work.
