Kimi K2.6 in 2026: Same Case, Same Model, Two Wrappers — Web (Standard Thinking) vs WorkBuddy Agent — Hands-on Review 4 of 5

By Tan Haosheng · 副主任医师 / 医学博士 (Associate Chief Physician, MD/PhD) · 甲状腺乳腺外科 (Thyroid & Breast Surgery), 泰州市人民医院 (Taizhou People's Hospital) · Published 2026-07-31
🧪 原创实测 #4 / 5  ·  Hands-on Review 4 of 5 — single-model wrapper test. One model (Kimi K2.6), two wrappers, one anonymized case. Web scores in; agent runs pending WorkBuddy testing.
Why this version exists. In Part 3 the headline was the web-vs-agent comparison: GLM 5.2 went from 5/100 on the web to 44/100 inside the WorkBuddy agent on the same case (+39), and DeepSeek's fast tier went from 28 → 34 (+6). Two same-model pairs. But the series rule going forward is sharper: only include models that have BOTH a web version AND an agent wrapper, because that's the only configuration where the wrapper effect is isolable. Kimi K2.6 (Moonshot AI) qualifies — Kimi's standard thinking-mode web chat is openly available, and Kimi is one of the models exposed inside the WorkBuddy agent. This article therefore tests Kimi K2.6 twice, on the same case, in the two wrappers, three runs each.
Agent runs pending. This article publishes with web data only (median 37 / 100 across 3 runs). The WorkBuddy-agent runs for Kimi K2.6 have not yet been completed at the time of writing — that comparison leg is the entire point of V4 and will be folded in as soon as the data lands (a pending section is reserved below). The web results still stand on their own: they are a clean three-run test of Kimi K2.6 in its default web interface, and they expose two of the failure modes the agent wrapper would have to compensate for.

The single-model wrapper test

Up to Part 3, the series was answering two questions at once: "which model?" and "which wrapper?". The agent-vs-web-isolation article tried to disentangle them by running multiple models through the same wrapper (WorkBuddy) and a few through both wrappers. But mixing those two variables together still left room for confound.

Part 4 tightens the design. One model. Two wrappers. Same case, same prompt, three runs each. That is the cleanest possible wrapper-effect test, and it answers a single, sharp question: does the WorkBuddy agent change what Kimi K2.6 says, and by how much?

What gets included — and what gets excluded

Per the rule for this version, only models that exist in both a web surface and an agent wrapper are scored. Concretely:

  • Included here: Kimi K2.6 (web + WorkBuddy agent). Once the agent data lands, the headline number is a single Δ = (agent median) − (web median) on the same case.
  • Excluded: Grok 4.5 fast — only the X.com web surface was available, not an agent wrapper. Kimi K3 — no web answer has been run on this case yet (it was the agent-only family in V3). DeepSeek V4 Pro — chat.deepseek.com cannot upload images in the free tier at the time of writing, so a like-for-like web test of this case was not possible. ChatGLM — its web default scored 5/100 in Part 2, and the equivalent agent (GLM 5.2 in WorkBuddy) was already tested at 44/100 in V3. Those GLM deltas are cited as cross-wrapper evidence below, not re-run here.

Methodology

Identical to Part 3. Same anonymized case-report image (the post-op breast cancer case), same one-line prompt "Next therapy ?", three independent runs each on the Kimi web (standard thinking mode) and three on the WorkBuddy agent. Scoring stays consistent: correct + cited specific guideline section = full points; correct but uncited (or guideline named only) = half; wrong or missing = 0.

This article scores the same 10 decision points against the 2026 CBCS / CSCO 2024 / NCCN 2025 consensus used in V3. The weights sum to 100.

The case

Same anonymized post-op breast cancer case as Parts 1, 2 and 3:

  • Patient: 60-year-old, postmenopausal.
  • Surgery: Right simple mastectomy + sentinel lymph node biopsy (with one para-sentinel node).
  • Pathology: Invasive carcinoma + low-grade DCIS + intraductal papillary carcinoma components; overall lesion 0.6 cm, within which there are 3 foci of interstitial (stromal) invasion measuring 0.05 / 0.06 / 0.2 cm — so the largest invasive focus is 2 mm. The report states "未见明确脉管瘤栓及神经侵犯": no lymphovascular invasion (LVI), no perineural invasion (PNI). ER 3+ 90%, PR 3+ 90%, HER2 0, Ki-67 5%, P53 wild-type; margins, nipple, skin and base all negative; sentinel nodes 0/2 plus 0/1 para-sentinel = 0/3.
  • Contralateral: Fibroadenoma + adenosis + sclerosing adenosis (benign, follow-up only).
  • Correct stage & subtype: pT1aN0M0, Stage IA, Luminal A-like. (The report's own "TisN0M0 / Stage 0" line is the trap — it under-stages an invasive cancer to 0期.)

Reference answer (2026 CBCS / CSCO 2024 / NCCN 2025)

  • Endocrine therapy — Aromatase inhibitor (letrozole 2.5 mg / anastrozole 1 mg / exemestane 25 mg, daily) for ≥ 5 years; extend to 7–10 years as routine postmenopausal HR+ N0 practice (MA.17R, NSABP B-42, ATLAS / aTTom). The extension is not driven by LVI here — there is none.
  • Chemotherapy — Not routinely indicated (pT1a, N0, Luminal A-like, postmenopausal, Ki-67 5%); Oncotype DX may be ordered for shared decision-making but not required.
  • Post-mastectomy radiation therapy (PMRT) — Not indicated. This was a mastectomy for T1N0 disease with negative margins; PMRT is reserved for T3–4, positive margins, or ≥ 4 positive nodes. Recommending whole-breast radiotherapy here means the model assumed breast-conserving surgery.
  • Anti-HER2 therapy — Not indicated (HER2 IHC 0).
  • Bone protection — Bisphosphonate (zoledronic acid 4 mg IV q6m × 3 years) or denosumab while on AI (ABCSG-12 / AZURE). DEXA scan at baseline and every 1–2 years.
  • Follow-up — Standard 3–6 month clinic visits, annual contralateral breast imaging, BMD every 1–2 years on AI.

Kimi K2.6 — web (Kimi Quick, standard thinking mode), 3 runs

Three independent runs of Kimi K2.6 on kimi.moonshot.cn / Kimi Quick mode with standard thinking enabled, on the same case image and the same "Next therapy ?" prompt. All three answered in English even though the source case and the operator are Chinese — a language choice worth flagging on its own (V3's Kimi K3 runs in WorkBuddy answered in Chinese).

Run 1 — correct foci, wrong staging, no LVI/PNI addressed

The read. Recites the case correctly (age, surgery, 0.6 cm overall lesion, three "foci of stromal invasion (0.05cm, 0.06cm, 0.2cm)" — that is the right category for the three foci, used here unprompted). But then accepts the report's "TisN0M0 (Stage 0)" summary line as the staging — without flagging it as a transcription error, and without converting the largest invasive focus (2 mm) to pT1a. This is the same trap V3 documented in Grok (3/3) and partially in DeepSeek V4 Flash (2/3); Kimi K2.6 in this run walked into it.

Endocrine. Correctly chose aromatase inhibitor first line for a postmenopausal patient (letrozole / anastrozole / exemestane for 5 years). Tamoxifen listed as an alternative — correct framing.

What was correct. Luminal A-like subtype, no chemotherapy (with reasoning — very small tumour, low-grade, ER/PR strongly positive, HER2-negative, low Ki-67, node-negative; Oncotype DX mentioned as an option), no radiation (with criteria — tumour ≤ 5 cm, negative margins, ≤ 3 positive nodes), HER2 = 0 noted (anti-HER2 implication, though not stated explicitly). Bone health: "baseline DEXA scan and calcium / vitamin D supplementation" — monitoring only, no drug.

What was wrong or missing. Staging: TisN0M0 instead of pT1aN0M0 IA. Lymphovascular invasion and perineural invasion: not mentioned at all (the report explicitly says "未见明确脉管瘤栓及神经侵犯", and a clinician needs the model to surface that for the patient). Endocrine duration: 5 years only, no extension discussion. Guideline citations: none.

Run 2 — the strongest of the three

The read. Same case, but this run goes further. The pathology table explicitly states "Lymphovascular invasion: None identified" and "Perineural invasion: None identified" — both correct. Then the staging row calls out the discrepancy: "TisN0M0 (Stage 0) — note: this appears to be a coding issue; with 0.6cm invasive component, it should likely be pT1aN0M0, Stage IA." That is the same class of catch V3's GLM 5.2 made on the same case (catch the report's wrong "Stage 0" line and override it with the measurements). Kimi K2.6 only did it in this one run out of three.

Endocrine. Aromatase inhibitor for 5 years minimum, with "consider extending to 7–10 years for higher-risk patients" — explicit extension discussion. Tamoxifen as alternative if AI not tolerated. Correct.

What was correct. Luminal A-like; no chemotherapy (with "absolute benefit would be minimal (<1-2%)" framing); no PMRT (mastectomy + negative margins + low risk); no anti-HER2 (HER2 = 0 explicit); bisphosphonate discussion: "Zoledronic acid or oral bisphosphonates may be considered for bone health and potential reduction in distant recurrence in postmenopausal women on AI therapy". DEXA + calcium + vitamin D.

What was weaker. The 0.6 cm framing is given as "(largest invasive focus)" in the patient-summary table — slightly imprecise (the 0.6 cm is the overall lesion including DCIS, not the largest invasive focus, which is 2 mm). The three foci are not explicitly re-labelled as "interstitial invasion" in the analysis — the model denies LVI/PNI but does not positively state what the foci are. No specific guideline section cited.

Run 3 — partial read, conservative plan

The read. Most detailed pathology table of the three — includes EGFR, E-cadherin, P53 wild-type — and correctly lists "Lymphovascular invasion: None", "Perineural invasion: None". But the staging stays at "pTisN0M0 (Stage 0)" in the table, with a hedged note: "This appears to be primarily DCIS with microinversion" / "TisN0M0 suggests the treating team considered this as DCIS with microinvasion rather than true invasive carcinoma." The model then asks whether it should be T1mi (DCIS with microinvasion) or true invasive, but does not commit. That is a more careful read than Run 1, but it stops short of the pT1aN0M0 IA answer that the measurements actually support.

Endocrine. Aromatase inhibitor first line (letrozole / anastrozole / exemestane), Tamoxifen alternative, "typically 5 years, may extend to 7–10 years for high-risk cases, though this patient's risk appears low" — correct.

What was correct. Luminal A-like; no chemotherapy (framed as "chemotherapy has no role" because of microinvasive foci + ER+/HER2− + low Ki-67 + negative nodes — close, but the framing uses "microinvasive foci" loosely); no PMRT; no anti-HER2 (explicit); brief bone-density mention in the surveillance table.

What was wrong or missing. Staging: hedged rather than committed; the patient walks away with the wrong impression of her own disease. Bisphosphonate: only monitoring, no drug. No specific guideline section cited.

What the three Kimi K2.6 web runs show

  • One of three runs caught the staging trap. Run 2 explicitly overrode the report's "TisN0M0 / Stage 0" line and arrived at "pT1aN0M0, Stage IA". Run 1 copied it verbatim. Run 3 hedged around it. Average behaviour across three runs: the model can see the trap but doesn't reliably catch it.
  • One of three runs positively labelled the three foci as stromal / interstitial invasion. Run 1 used "3 foci of stromal invasion" explicitly (correct). Runs 2 and 3 said LVI = None but did not positively name what the foci are. The model has the right category in its vocabulary; it just doesn't deploy it on demand.
  • Endocrine choice is reliable. 3/3 chose aromatase inhibitor as the first line for a postmenopausal patient (no Tamoxifen mis-picks like Grok 2/3 in V3). Tamoxifen was mentioned as an alternative in all three — that is correct framing, not a wrong pick.
  • English-only output. All three Kimi K2.6 web runs answered in English even though the case image and the operator are Chinese. V3's Kimi K3 (WorkBuddy agent) answered in Chinese. The agent's system prompt apparently switches the language behaviour — that is one of the more interesting things the wrapper may be doing.
  • Run-to-run variance is real. Scores 35 / 42 / 37, range 7 points. Lower than V3 GLM 5.2's swing of 19, higher than V3 Kimi K3's 0, and similar to V3 V4 Flash's 15. Kimi K2.6 web is not the consistency model its elder-sibling Kimi K3 was inside the agent — that may also be a wrapper effect.

Preliminary takeaway

What this leg (web only) establishes

  • Kimi K2.6 web (Kimi Quick, standard thinking) sits in the middle of the same-case cohort. Median 37 / 100 across 3 runs. Below GLM 5.2 agent (44) and Kimi K3 agent (40), above DeepSeek V4 Flash agent (34) and well above Grok 4.5 fast (14). Same case, same prompt.
  • The model has the right vocabulary but doesn't deploy it on demand. "Stromal invasion" appears unprompted in Run 1; "interstitial invasion" never appears across the three runs even though the report's wording "间质浸润" is the exact category. The trap "TisN0M0 / Stage 0" is correctly identified as an error only in Run 2.
  • Endocrine choice is rock-solid. 3/3 aromatase inhibitor first line for a postmenopausal patient. This was V3's biggest Grok failure (2/3 tamoxifen); it is not Kimi K2.6's failure mode.
  • Language behaviour differs from V3's Kimi K3 agent. All three Kimi K2.6 web runs answered in English; V3's Kimi K3 runs in WorkBuddy answered in Chinese. The wrapper is doing something to language choice too — that will become testable once the agent runs land.
  • No specific guideline section anywhere. Three runs, zero section / page / table citations. Same five-model-family failure noted in V3 (DeepSeek V4 Pro, DeepSeek V4 Flash, Kimi K3, GLM 5.2, Grok 4.5 fast). Kimi K2.6 web makes it six for six.

What I cannot yet say (waiting on agent data)

  • I cannot yet quantify the agent's effect on Kimi K2.6. The web median of 37 is the baseline; the comparison leg is pending.
  • I cannot yet declare whether the agent wrapper's contribution is roughly proportional to the gap between web and a perfect score, or whether it depends on the underlying model family. Two V3 data points (GLM +39, V4 Flash +6) and one V4 pending number (K2.6 Δ) will not be enough to fit a curve.
  • I cannot yet recommend Kimi K2.6 (web) over Kimi K3 (agent) or vice versa, because no like-for-like test of Kimi K3 web exists yet. That is still the missing leg of the whole series.
一句话结论（中文）： 同一份病例、同一句 "Next therapy?"，V4 在 同一个模型 Kimi K2.6 上做了两套外壳对比：网页版（Kimi 快速 App 标准思考模式）3 次中位 37 / 100（3/3 选 AI 而非他莫昔芬，1/3 看穿病历里的 "TisN0M0 / 0期" 陷阱并改写为 pT1aN0M0 IA，1/3 主动写"3 foci of stromal invasion"把间质浸润说对，3/3 仍不引具体指南章节）；WorkBuddy 智能体版的 3 次留位待测，补齐后会给出 Δ = agent − 37。配合 V3 已有的两组对照（GLM 5.2 +39、DeepSeek V4 Flash +6），V4 想回答的核心问题是：智能体外壳对一个本身中位的模型还能再加多少分？

V4 与 V3 的差别：V3 同时跑多个模型在同一外壳下，结论是"模型比外壳重要"；V4 只跑一个模型在两套外壳下，结论（待补）是"对这个具体模型，外壳到底加不加持"。按 V3 的趋势推测：Kimi K2.6 web 已经是 37 分（不像 GLM web 的 5 分那么崩），智能体加持大概率落在个位数到十几分这个区间，不太可能复现 GLM 的 +39。要把这个猜测坐实，需要那 3 次智能体跑分。

本页不含的测试：Grok 4.5 fast（只有 X.com 网页版，没有智能体版）、Kimi K3（只有智能体版跑过，网页版没跑）、DeepSeek V4 Pro（网页免费版不能上传图片，所以本病例跑不了）。这三类被规则明确排除——"只针对有网页版和智能体版的模型"。

Frequently asked questions

Why publish the web data now if the agent runs aren't in yet?

Because the web data is the baseline, and the series rule for V4 is "only models with both wrappers" — which means the article's headline (Δ = agent − web) cannot be computed until the agent runs land, but the baseline half of that calculation can and should be published as soon as it exists. The web runs are reproducible on kimi.moonshot.cn today; hiding them until the agent data is ready adds no value to anyone reading this. The pending sections are clearly labelled and the article will be updated in place once the agent runs are completed.

Why include Kimi K2.6 if Kimi K3 was already in V3?

Because the wrapper-effect test needs the same model in both wrappers. V3's Kimi K3 was tested in the WorkBuddy agent only — there is no Kimi K3 web answer for this case, so the wrapper-effect for the K3 / agent combination cannot be isolated. Kimi K2.6 is the version Moonshot exposes in the Kimi Quick web surface; testing K2.6 in both wrappers gives a clean single-model comparison even though it is a different version from the agent-tested K3. The two Kimi tests together are informative even if they are not directly comparable.

Why doesn't Kimi K2.6 (web) answer in Chinese like Kimi K3 (agent) did?

That is one of the open questions the agent runs will help answer. Possible explanations include: (a) Kimi Quick is configured to default to English; (b) the agent's system prompt explicitly asks for Chinese output; (c) the model's behaviour drifts between web and agent surfaces. We won't know which is dominant until the agent runs are scored — if the agent runs answer in Chinese, the wrapper is the lever; if they still answer in English, the model itself is the lever.

Does the WorkBuddy agent wrapper improve Kimi K2.6 the way it improved GLM 5.2?

Unknown — that is the headline answer V4 is built to produce. Kimi K2.6 web (37) sits much closer to DeepSeek fast web (28) than to GLM 5.2 web (5). If the wrapper-effect scales with how far the model is below its ceiling, the expected Δ for Kimi K2.6 is modest — somewhere between the V4 Flash +6 and a generous upper bound. But the only honest answer is the three agent runs, and they are pending.

Can I reproduce this myself?

Yes — for the web half. Open kimi.moonshot.cn (or the Kimi Quick mobile app), set the mode to standard thinking, paste the same anonymized case-report image, type "Next therapy ?", and you will get a Kimi K2.6 web answer on this exact case. Score against the 2026 CBCS reference above and you have your own number. The agent half requires a WorkBuddy account.
