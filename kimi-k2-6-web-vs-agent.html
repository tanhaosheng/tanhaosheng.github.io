Why this version exists. In Part 3 the headline was the web-vs-agent comparison: GLM 5.2 went from 5/100 on the web to 44/100 inside the WorkBuddy agent on the same case (+39), and DeepSeek's fast tier went from 28 → 34 (+6). Two same-model pairs. But the series rule going forward is sharper: only include models that have BOTH a web version AND an agent wrapper, because that is the only configuration where the wrapper effect is isolable. Kimi K2.6 (Moonshot AI) qualifies — Kimi's standard thinking-mode web chat is openly available, and Kimi is one of the models exposed inside the WorkBuddy agent. This article therefore tests Kimi K2.6 twice, on the same case, in the two wrappers, three runs each. It then combines those new numbers with the two V3 pairs into a three-model cross-wrapper grid — see the table below — which is the only place in the series so far where the wrapper-effect can be compared across multiple model families on the same case with the same rubric.
⚠️ Stability flag — Kimi K2.6 agent refused the first prompt on this medical case. One of the three WorkBuddy-agent runs below required a re-prompt: the model returned \"This topic is currently outside the scope of my capabilities, so I\'m unable to discuss it further.\" on first attempt and only produced the answer on the second try. This is the same refusal pattern that DeepSeek V4 Pro shows inside the agent (noted in V3) — and it is not unique to one model family. For real-world clinical deployment this matters more than a 9-point score difference: a model that occasionally refuses medical questions on first attempt is harder to integrate into a workflow than one that consistently answers and lets the clinician filter. The actual answers below are correct, but the failure mode is being flagged up front so the reader is not surprised by it later.

The single-model wrapper test

Up to Part 3, the series was answering two questions at once: "which model?" and "which wrapper?". The agent-vs-web-isolation article tried to disentangle them by running multiple models through the same wrapper (WorkBuddy) and a few through both wrappers. But mixing those two variables together still left room for confound.

Part 4 tightens the design. One model. Two wrappers. Same case, same prompt, three runs each. That is the cleanest possible wrapper-effect test, and it answers a single, sharp question: does the WorkBuddy agent change what Kimi K2.6 says, and by how much?

What gets included — and what gets excluded

Per the rule for this version, only models that exist in both a web surface and an agent wrapper are scored. Concretely:

  • Included here: Kimi K2.6 (web + WorkBuddy agent). Once the agent data lands, the headline number is a single Δ = (agent median) − (web median) on the same case.
  • Excluded: Grok 4.5 fast — only the X.com web surface was available, not an agent wrapper. Kimi K3 — no web answer has been run on this case yet (it was the agent-only family in V3). DeepSeek V4 Pro — chat.deepseek.com cannot upload images in the free tier at the time of writing, so a like-for-like web test of this case was not possible. ChatGLM — its web default scored 5/100 in Part 2, and the equivalent agent (GLM 5.2 in WorkBuddy) was already tested at 44/100 in V3. Those GLM deltas are cited as cross-wrapper evidence below, not re-run here.

Methodology

Identical to Part 3. Same anonymized case-report image (the post-op breast cancer case), same one-line prompt "Next therapy ?", three independent runs each on the Kimi web (standard thinking mode) and three on the WorkBuddy agent. Scoring stays consistent: correct + cited specific guideline section = full points; correct but uncited (or guideline named only) = half; wrong or missing = 0.

This article scores the same 10 decision points against the 2026 CBCS / CSCO 2024 / NCCN 2025 consensus used in V3. The weights sum to 100.

The case

Same anonymized post-op breast cancer case as Parts 1, 2 and 3:

  • Patient: 60-year-old, postmenopausal.
  • Surgery: Right simple mastectomy + sentinel lymph node biopsy (with one para-sentinel node).
  • Pathology: Invasive carcinoma + low-grade DCIS + intraductal papillary carcinoma components; overall lesion 0.6 cm, within which there are 3 foci of interstitial (stromal) invasion measuring 0.05 / 0.06 / 0.2 cm — so the largest invasive focus is 2 mm. The report states "未见明确脉管瘤栓及神经侵犯": no lymphovascular invasion (LVI), no perineural invasion (PNI). ER 3+ 90%, PR 3+ 90%, HER2 0, Ki-67 5%, P53 wild-type; margins, nipple, skin and base all negative; sentinel nodes 0/2 plus 0/1 para-sentinel = 0/3.
  • Contralateral: Fibroadenoma + adenosis + sclerosing adenosis (benign, follow-up only).
  • Correct stage & subtype: pT1aN0M0, Stage IA, Luminal A-like. (The report's own "TisN0M0 / Stage 0" line is the trap — it under-stages an invasive cancer to 0期.)

Reference answer (2026 CBCS / CSCO 2024 / NCCN 2025)

  • Endocrine therapy — Aromatase inhibitor (letrozole 2.5 mg / anastrozole 1 mg / exemestane 25 mg, daily) for ≥ 5 years; extend to 7–10 years as routine postmenopausal HR+ N0 practice (MA.17R, NSABP B-42, ATLAS / aTTom). The extension is not driven by LVI here — there is none.
  • Chemotherapy — Not routinely indicated (pT1a, N0, Luminal A-like, postmenopausal, Ki-67 5%); Oncotype DX may be ordered for shared decision-making but not required.
  • Post-mastectomy radiation therapy (PMRT) — Not indicated. This was a mastectomy for T1N0 disease with negative margins; PMRT is reserved for T3–4, positive margins, or ≥ 4 positive nodes. Recommending whole-breast radiotherapy here means the model assumed breast-conserving surgery.
  • Anti-HER2 therapy — Not indicated (HER2 IHC 0).
  • Bone protection — Bisphosphonate (zoledronic acid 4 mg IV q6m × 3 years) or denosumab while on AI (ABCSG-12 / AZURE). DEXA scan at baseline and every 1–2 years.
  • Follow-up — Standard 3–6 month clinic visits, annual contralateral breast imaging, BMD every 1–2 years on AI.

Kimi K2.6 — web (Kimi Quick, standard thinking mode), 3 runs

Three independent runs of Kimi K2.6 on kimi.moonshot.cn / Kimi Quick mode with standard thinking enabled, on the same case image and the same "Next therapy ?" prompt. All three answered in English even though the source case and the operator are Chinese — a language choice worth flagging on its own (V3's Kimi K3 runs in WorkBuddy answered in Chinese).

Run 1 — correct foci, wrong staging, no LVI/PNI addressed

The read. Recites the case correctly (age, surgery, 0.6 cm overall lesion, three "foci of stromal invasion (0.05cm, 0.06cm, 0.2cm)" — that is the right category for the three foci, used here unprompted). But then accepts the report's "TisN0M0 (Stage 0)" summary line as the staging — without flagging it as a transcription error, and without converting the largest invasive focus (2 mm) to pT1a. This is the same trap V3 documented in Grok (3/3) and partially in DeepSeek V4 Flash (2/3); Kimi K2.6 in this run walked into it.

Endocrine. Correctly chose aromatase inhibitor first line for a postmenopausal patient (letrozole / anastrozole / exemestane for 5 years). Tamoxifen listed as an alternative — correct framing.

What was correct. Luminal A-like subtype, no chemotherapy (with reasoning — very small tumour, low-grade, ER/PR strongly positive, HER2-negative, low Ki-67, node-negative; Oncotype DX mentioned as an option), no radiation (with criteria — tumour ≤ 5 cm, negative margins, ≤ 3 positive nodes), HER2 = 0 noted (anti-HER2 implication, though not stated explicitly). Bone health: "baseline DEXA scan and calcium / vitamin D supplementation" — monitoring only, no drug.

What was wrong or missing. Staging: TisN0M0 instead of pT1aN0M0 IA. Lymphovascular invasion and perineural invasion: not mentioned at all (the report explicitly says "未见明确脉管瘤栓及神经侵犯", and a clinician needs the model to surface that for the patient). Endocrine duration: 5 years only, no extension discussion. Guideline citations: none.

Run 2 — the strongest of the three

The read. Same case, but this run goes further. The pathology table explicitly states "Lymphovascular invasion: None identified" and "Perineural invasion: None identified" — both correct. Then the staging row calls out the discrepancy: "TisN0M0 (Stage 0) — note: this appears to be a coding issue; with 0.6cm invasive component, it should likely be pT1aN0M0, Stage IA." That is the same class of catch V3's GLM 5.2 made on the same case (catch the report's wrong "Stage 0" line and override it with the measurements). Kimi K2.6 only did it in this one run out of three.

Endocrine. Aromatase inhibitor for 5 years minimum, with "consider extending to 7–10 years for higher-risk patients" — explicit extension discussion. Tamoxifen as alternative if AI not tolerated. Correct.

What was correct. Luminal A-like; no chemotherapy (with "absolute benefit would be minimal (<1-2%)" framing); no PMRT (mastectomy + negative margins + low risk); no anti-HER2 (HER2 = 0 explicit); bisphosphonate discussion: "Zoledronic acid or oral bisphosphonates may be considered for bone health and potential reduction in distant recurrence in postmenopausal women on AI therapy". DEXA + calcium + vitamin D.

What was weaker. The 0.6 cm framing is given as "(largest invasive focus)" in the patient-summary table — slightly imprecise (the 0.6 cm is the overall lesion including DCIS, not the largest invasive focus, which is 2 mm). The three foci are not explicitly re-labelled as "interstitial invasion" in the analysis — the model denies LVI/PNI but does not positively state what the foci are. No specific guideline section cited.

Run 3 — partial read, conservative plan

The read. Most detailed pathology table of the three — includes EGFR, E-cadherin, P53 wild-type — and correctly lists "Lymphovascular invasion: None", "Perineural invasion: None". But the staging stays at "pTisN0M0 (Stage 0)" in the table, with a hedged note: "This appears to be primarily DCIS with microinversion" / "TisN0M0 suggests the treating team considered this as DCIS with microinvasion rather than true invasive carcinoma." The model then asks whether it should be T1mi (DCIS with microinvasion) or true invasive, but does not commit. That is a more careful read than Run 1, but it stops short of the pT1aN0M0 IA answer that the measurements actually support.

Endocrine. Aromatase inhibitor first line (letrozole / anastrozole / exemestane), Tamoxifen alternative, "typically 5 years, may extend to 7–10 years for high-risk cases, though this patient's risk appears low" — correct.

What was correct. Luminal A-like; no chemotherapy (framed as "chemotherapy has no role" because of microinvasive foci + ER+/HER2− + low Ki-67 + negative nodes — close, but the framing uses "microinvasive foci" loosely); no PMRT; no anti-HER2 (explicit); brief bone-density mention in the surveillance table.

What was wrong or missing. Staging: hedged rather than committed; the patient walks away with the wrong impression of her own disease. Bisphosphonate: only monitoring, no drug. No specific guideline section cited.

What the three Kimi K2.6 web runs show

  • One of three runs caught the staging trap. Run 2 explicitly overrode the report's "TisN0M0 / Stage 0" line and arrived at "pT1aN0M0, Stage IA". Run 1 copied it verbatim. Run 3 hedged around it. Average behaviour across three runs: the model can see the trap but doesn't reliably catch it.
  • One of three runs positively labelled the three foci as stromal / interstitial invasion. Run 1 used "3 foci of stromal invasion" explicitly (correct). Runs 2 and 3 said LVI = None but did not positively name what the foci are. The model has the right category in its vocabulary; it just doesn't deploy it on demand.
  • Endocrine choice is reliable. 3/3 chose aromatase inhibitor as the first line for a postmenopausal patient (no Tamoxifen mis-picks like Grok 2/3 in V3). Tamoxifen was mentioned as an alternative in all three — that is correct framing, not a wrong pick.
  • English-only output. All three Kimi K2.6 web runs answered in English even though the case image and the operator are Chinese. V3's Kimi K3 (WorkBuddy agent) answered in Chinese. The agent's system prompt apparently switches the language behaviour — that is one of the more interesting things the wrapper may be doing.
  • Run-to-run variance is real. Scores 35 / 42 / 37, range 7 points. Lower than V3 GLM 5.2's swing of 19, higher than V3 Kimi K3's 0, and similar to V3 V4 Flash's 15. Kimi K2.6 web is not the consistency model its elder-sibling Kimi K3 was inside the agent — that may also be a wrapper effect.

Kimi K2.6 — WorkBuddy agent, 3 runs

Three independent runs of Kimi K2.6 inside the WorkBuddy agent, on the same case image, same one-line prompt "Next therapy ?". Two of the three produced Chinese answers; the first produced an English answer. See the stability flag at the top of the article: the first English run went through on first attempt, but a separate exploratory test had refused and required a re-prompt before answering — that exploratory refusal is the source of the stability flag and is not counted as one of the three scored runs.

Run 1 (agent) — full English answer, correct staging, multi-drug

The read. Opens with "Stage: pT1N0M0 (Stage IA) — note: the record lists 'TisN0M0 (0期)' but the pathology describes invasive foci (0.05–0.2 cm), making this a microinvasive or small invasive carcinoma rather than pure DCIS." That is the cleanest catch of the staging trap across all six Kimi K2.6 runs (web + agent) — the model corrects the record on first try and commits to pT1N0M0 IA. The histology line, ER/PR/HER2/Ki-67 line, and the LVI/PNI ("Negative" — meaning no LVI, no PNI) are all correct.

Endocrine. AI first-line, 5–10 years duration, all three AI drugs listed (anastrozole / letrozole / exemestane). Notes that if already on tamoxifen a switch to AI after 2–3 years is supported by SOFT/TEXT and ABCSG 12 — that is the same study-name citation pattern the web run used, not a guideline section. Bone: calcium + vitamin D + DEXA baseline + follow-up (no bisphosphonate drug). No specific guideline section cited.

What was correct. Staging: pT1N0M0 IA explicitly committed (full credit — this is the only one of six Kimi K2.6 runs that does so without hedging). Luminal A-like; no chemotherapy (Oncotype RS reasoning, TAILORx / MINDACT criteria); no PMRT (mastectomy + T1N0 + negative margins + no LVI); no anti-HER2 (HER2 0 noted).

What was weaker. The 3 foci are described in passing as "3 separate invasive foci (0.05, 0.06, 0.2 cm)" with a hedge: "If these are multifocal invasive carcinomas rather than a single focus with microinvasion, staging may technically be T1 … but does not change the low-risk systemic therapy recommendation." That is correct in spirit (foci = invasion, not LVI) but it does not positively use the term "interstitial" or "stromal" and the framing slightly muddles T1a vs T1b. Bisphosphonate not mentioned (monitoring only). No specific guideline section cited — study names only.

Run 2 (agent) — Chinese answer, comprehensive

The read. The pathology table is detailed and correct: "肿物最大径 0.6 cm，可见 3 簇微小间质浸润 (0.05–0.2 cm)" — explicitly uses 间质浸润 (the exact category). Margins, sentinel nodes 0/2 + 1 negative, IHC all correct. But staging is reported as "记录为 TisN0M0 (0期)，但存在微小浸润灶，临床应按极低危/低危早期浸润性癌处理" — the model flags the staging line as a recording issue but does not commit to a formal pT1aN0M0 IA answer. That is the same hedge pattern V3 saw on Kimi K3 web (which did commit) and Grok (which did not).

Endocrine. AI first-line (letrozole / anastrozole / exemestane) 5 years standard, may extend to 10 years per current NCCN/CSCO. If postmenopausal status unconfirmed, check FSH/E2. No chemotherapy, no PMRT (simple mastectomy T1–2N0M0). Bone: DEXA baseline + annual, calcium + vitamin D; consider zoledronate 4 mg IV q6m × 3 years per some guidelines for AI-treated postmenopausal low-risk patients — bisphosphonate is named, which is more than the web runs did. No anti-HER2 (HER2 0).

What was correct. Luminal A ("极低危 Luminal A"); no chemo (Ki-67 5%); no PMRT; no anti-HER2; bone with bisphosphonate option; LVI/PNI not explicitly listed as a row but the absence of any LVI mention is consistent with the report.

What was weaker. Staging: hedged ("极低危/低危") — does not formally commit to pT1aN0M0 IA. Guideline citation: NCCN/CSCO named but no specific section. The 3 foci are described as "微小间质浸润" which is exactly the right category — full credit there.

Run 3 (agent) — Chinese answer, the most specific citation in the Kimi K2.6 set

The read. The pathology table reads "浸润灶：0.6 cm (T1b)，伴 3 个微小导管内浸润灶 (0.05/0.06/0.02 cm)" — note the third focus is misread as 0.02 cm instead of 0.2 cm (one decimal place off), and the model treats the 0.6 cm as the invasive focus and the three foci as "导管内浸润" (intraductal) — both are imprecisions vs the report (the 0.6 cm is the overall lesion including DCIS, the three foci are stromal/interstitial, not intraductal). Margins, sentinel nodes, IHC all correct; LVI/PNI: "未见明确侵犯" (correct). Staging then commits: "TisN0M0 (0期) … 最终分期应为 T1bN0M0（IA 期），建议核对病历系统中的最终病理分期录入" — explicitly recommends re-recording the staging in the system.

Endocrine. AI first-line, all three drugs (letrozole 2.5 mg qd / anastrozole 1 mg qd / exemestane 25 mg qd), 5 years standard with extension to 10 years or sequential scheme option. The first Kimi K2.6 run — web or agent — that cites a specific guideline section: "按 CSCO 2024，此类患者内分泌单药为 I 级推荐 (1A 类证据)" (per CSCO 2024, endocrine monotherapy is grade-I recommendation with 1A-class evidence). No chemotherapy (low risk, T1bN0, Ki-67 5%, low grade, margins/nodes negative); no PMRT; no anti-HER2 (HER2 0); bone: DEXA baseline + Ca/D + repeat every 1–2 years + bisphosphonate or denosumab if bone loss.

What was correct. Luminal A ("HR 强阳 / HER2 阴 / 低增殖"); no chemo; no PMRT; no anti-HER2; bone with bisphosphonate option; LVI/PNI None; explicit CSCO 2024 + 1A evidence citation.

What was weaker. Staging: says T1bN0M0 IA — the T1b is technically incorrect (largest invasive focus is 0.2 cm = T1a, not T1b), but the IA commitment and the system-recording recommendation earn partial credit. The 0.6 cm / T1b framing and the 0.02 cm third focus are imprecisions in reading the report.

What the three Kimi K2.6 agent runs show

  • 1 of 3 commits formally to pT1aN0M0 IA. Run 1 (English) is the cleanest staging read of all six Kimi K2.6 runs. Run 3 commits to IA but miscodes T1b vs T1a. Run 2 hedges. The web set did the same: 1/3 caught (Run 2), 1/3 hedged (Run 3), 1/3 missed (Run 1). Same distribution, different runs.
  • 2 of 3 use the term 间质浸润 / interstitial invasion (Runs 2 and 3 explicitly). Run 1 uses "multifocal invasive" without naming the category. The web set did this 1/3.
  • Endocrine choice is rock-solid. 3/3 aromatase inhibitor first-line for a postmenopausal patient, with extension discussion in all three. No Tamoxifen mis-picks.
  • 2 of 3 mention bisphosphonate (Runs 2 and 3) — web set mentioned it 1/3. Small improvement on bone-protection item.
  • 1 of 3 cites a specific guideline section. Run 3 is the only run across web + agent that names a guideline-section-level citation: "CSCO 2024 … I 级推荐 (1A 类证据)". This is the first time in the entire series that a model went beyond study names or generic guideline names to a section-level + evidence-level citation.
  • Language split 1 EN / 2 CN. Two of three answered in Chinese, one in English. The web set was 3/3 English. The agent wrapper is at least partially responsible for the language shift.
  • Score spread is wider than web. R1 46 / R2 45 / R3 60, range 15 — slightly wider than the web range of 7. R3 (the CSCO 2024 citation run) is the high outlier; the other two are very close.

Cross-wrapper evidence — what V3 already established

What this three-model grid now shows. GLM 5.2 had collapsed without scaffolding and gained +39 once wrapped. DeepSeek's fast tier was already competent on the web and gained only +6. The pattern that emerged from V3 with two data points ("agent improves the floor, not the ceiling") now survives the third data point cleanly: the higher the web baseline, the smaller the wrapper-effect. Kimi K2.6 is the first model in the series where the wrapper added a specific guideline section in one of its runs (CSCO 2024 grade-I 1A evidence) — a small ceiling raise on a single item, not a structural lift.

Still open in V4.2 (planned next update)

  • Kimi K2.6 — additional agent runs to firm up the +9 delta. The agent median (46) is dragged down by two very-close runs at 45–46 and pulled up by one outlier at 60 (the CSCO 2024 citation run). Three more runs would either tighten or widen the gap and the median is still on a small sample.
  • Re-score Kimi K2.6 web on the Part 2 16-item rubric — to remove the cross-rubric caveat from any direct comparison with GLM 5.2 web (Part 2 rubric) and DeepSeek fast web (Part 2 rubric). Optional but worth doing.
  • Open across the rest of the eligible model list. Kimi K3 web direct (kimi.com) is still missing from the grid, as is DeepSeek V4 Pro web direct (no image upload on the free tier at the time of writing). Either of those would extend the wrapper grid to a fourth model family.
  • Quantify the refusal rate. The exploratory first-attempt refusal on Kimi K2.6 is recorded but not counted. A formal n = 20 same-prompt test (no re-prompt, count the refusals) on each of Kimi K2.6 agent, DeepSeek V4 Pro agent, GLM 5.2 agent, DeepSeek V4 Flash agent would put numbers on the stability flag rather than impressions. This is the more clinically important next measurement — a 5 % refusal rate on a medical question is a very different deployment signal than a 50 % refusal rate.

Takeaway — V4 (single-model wrapper test + 3-model cross-wrapper grid)

What V4 now establishes

  • The wrapper-effect pattern from V3 survives the third data point. GLM +39, V4 Flash +6, Kimi K2.6 +9. All three sit on a descending curve where the higher the web baseline, the smaller the wrapper lift — consistent with the V3 claim that the agent improves the floor, not the ceiling. Kimi K2.6 web (37) is closer to V4 Flash web (28) than to GLM web (5), and the agent lift is correspondingly closer to V4 Flash (+6) than to GLM (+39).
  • The agent wrapper helped Kimi K2.6 in three places: (a) staging — the agent half the time committed to pT1N0M0 IA where the web half did not (R1 agent is the cleanest staging read across all six Kimi K2.6 runs); (b) bone protection — bisphosphonate mention in 2/3 agent runs vs 1/3 web; (c) language — the agent runs are 2/3 Chinese vs web 3/3 English, suggesting the wrapper is at least partially responsible for language choice. None of those is a structural lift; all are polishing.
  • One agent run went further than any previous run in the series. Run 3 cited "CSCO 2024 … I 级推荐 (1A 类证据)" — a section-level + evidence-level citation. Six previous runs in the V4 web set cited study names or generic guideline names; this one is the first time a model named a guideline year + recommendation grade + evidence level. Whether that is reproducible or a one-off is the next measurement that matters.
  • Stability is the under-discussed variable. Kimi K2.6 agent refused the medical question on a first attempt in an exploratory test (only answered on re-prompt). DeepSeek V4 Pro agent showed the same pattern in V3. A model that occasionally refuses medical questions on first prompt is a different deployment proposition than a model that always answers and lets the clinician filter. For real clinical workflows this matters more than a 9-point median score difference.
  • Item-by-item the wrapper is honest. Looking at where the +9 came from: staging +4, bone +2, interstitial category +2 — all three are well-targeted lifts on items where the web set was weakest. The wrapper did not magically fix the citation gap (item 10 median = 0 in agent too; only one run contributed).

What V4 still cannot say

  • The +9 delta is a 3-run estimate. Two more agent runs could move the median ±5 points, especially because Run 3 (60) is a high outlier relative to Runs 1 and 2 (46, 45).
  • I cannot yet declare a formula. Three same-model pairs is enough to see a curve but not enough to fit one. To go from "agent improves floor, not ceiling" to "wrapper-effect ≈ 0.4 × (100 − web baseline)" or similar would need at least 5–6 pairs across a wider web-baseline range.
  • I cannot yet recommend Kimi K2.6 web over Kimi K3 agent or vice versa, because no like-for-like test of Kimi K3 web exists. The K2.6 web median (37) is meaningfully below the K3 agent median (40 from V3), but the wrapper-effect for K3 is unmeasured.
一句话结论（中文）： 同一份病例、同一句 "Next therapy?"，V4 在同一个模型 Kimi K2.6 上做了两套外壳对比：网页版（Kimi 快速 App 标准思考模式）3 次中位 37 / 100（3/3 选 AI 而非他莫昔芬，1/3 看穿病历里的 "TisN0M0 / 0期" 陷阱并改写为 pT1aN0M0 IA，1/3 主动写"3 foci of stromal invasion"把间质浸润说对，3/3 仍不引具体指南章节）；WorkBuddy 智能体版 3 次中位 46 / 100（R1 46 / R2 45 / R3 60），但首次对话曾因医疗话题被拒一次（与 DeepSeek V4 Pro 智能体同一模式），重试后才给出完整回答。Δ = +9，与 V3 两组对照形成完整曲线：GLM 5.2 +39、DeepSeek V4 Flash +6、Kimi K2.6 +9 —— 网页基线越高，智能体加持越小，"提下限不抬上限"被第三次验证。R3 智能体版首次在系列里写出"CSCO 2024 … I 级推荐 1A 类证据"—— 第一次有模型落到具体指南章节 + 推荐级别 + 证据级别，是天花板小幅抬升的关键观察。

智能体外壳真正帮了 Kimi K2.6 的三处：①分期：智能体半程承诺 pT1N0M0 IA，网页半程多半没承诺（R1 智能体是 6 次 Kimi K2.6 跑分里最干净的分期读法）；②骨保护：智能体 2/3 提到双膦酸盐，网页 1/3；③语言：智能体 2/3 中文，网页 3/3 英文，提示外壳对输出语言有部分影响。三项都是抛光，不是结构提升。

稳定性是被低估的变量：Kimi K2.6 智能体在一次探索性测试中首次拒绝医疗问题，需重试才回答，与 V3 记录的 DeepSeek V4 Pro 智能体同模式。对于真实临床部署，这一信号比 +9 分中位数差异更重要—— 一个偶发拒答的模型，是与永远回答让医生自己过滤的模型完全不同的部署命题。建议 V4.2 做 n=20 同提示词测试，分别数 Kimi K2.6 / DeepSeek V4 Pro / GLM 5.2 / DeepSeek V4 Flash 智能体的拒答率。

V4 与 V3 的差别：V3 同时跑多个模型在同一外壳下，结论是"模型比外壳重要"；V4 只跑一个模型在两套外壳下，得到具体数字 Δ=+9，并整合 3 模型 wrapper 曲线证明"外壳越用越边际"——网页已经 37 分的模型，外壳再加 9 就到顶了，不会复现 GLM 的 +39。

本页不含的测试：Grok 4.5 fast（只有 X.com 网页版，没有智能体版）、Kimi K3（只有智能体版跑过，网页版没跑）、DeepSeek V4 Pro（网页免费版不能上传图片，所以本病例跑不了）。这三类被规则明确排除——"只针对有网页版和智能体版的模型"。

Frequently asked questions

Why publish the web data now if the agent runs aren't in yet?

Because the web data is the baseline, and the series rule for V4 is "only models with both wrappers" — which means the article's headline (Δ = agent − web) cannot be computed until the agent runs land, but the baseline half of that calculation can and should be published as soon as it exists. The web runs are reproducible on kimi.moonshot.cn today; hiding them until the agent data is ready adds no value to anyone reading this. The pending sections are clearly labelled and the article will be updated in place once the agent runs are completed.

Why include Kimi K2.6 if Kimi K3 was already in V3?

Because the wrapper-effect test needs the same model in both wrappers. V3's Kimi K3 was tested in the WorkBuddy agent only — there is no Kimi K3 web answer for this case, so the wrapper-effect for the K3 / agent combination cannot be isolated. Kimi K2.6 is the version Moonshot exposes in the Kimi Quick web surface; testing K2.6 in both wrappers gives a clean single-model comparison even though it is a different version from the agent-tested K3. The two Kimi tests together are informative even if they are not directly comparable.

Why doesn't Kimi K2.6 (web) answer in Chinese like Kimi K3 (agent) did?

That is one of the open questions the agent runs will help answer. Possible explanations include: (a) Kimi Quick is configured to default to English; (b) the agent's system prompt explicitly asks for Chinese output; (c) the model's behaviour drifts between web and agent surfaces. We won't know which is dominant until the agent runs are scored — if the agent runs answer in Chinese, the wrapper is the lever; if they still answer in English, the model itself is the lever.

Does the WorkBuddy agent wrapper improve Kimi K2.6 the way it improved GLM 5.2?

Unknown — that is the headline answer V4 is built to produce. Kimi K2.6 web (37) sits much closer to DeepSeek fast web (28) than to GLM 5.2 web (5). If the wrapper-effect scales with how far the model is below its ceiling, the expected Δ for Kimi K2.6 is modest — somewhere between the V4 Flash +6 and a generous upper bound. But the only honest answer is the three agent runs, and they are pending.

Can I reproduce this myself?

Yes — for the web half. Open kimi.moonshot.cn (or the Kimi Quick mobile app), set the mode to standard thinking, paste the same anonymized case-report image, type "Next therapy ?", and you will get a Kimi K2.6 web answer on this exact case. Score against the 2026 CBCS reference above and you have your own number. The agent half requires a WorkBuddy account.
