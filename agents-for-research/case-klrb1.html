Case 1 — KLRB1 + breast cancer scRNA-seq

By Tan Haosheng, MD, PhD · Last reviewed 2026-07-31

One-shot18 min 05 s wall-clockWorkBuddy Hy32 samples · 1 patientReproducible transcript

Two anonymized breast-cancer single-cell samples sit on my laptop. I genuinely forgot which one was CD45-sorted and which one wasn't. I attached both, plus my own KLRB1/BRCA manuscript, and gave one prompt. This is what the agent did in 18 minutes 5 seconds, first try — including the three places where it caught me over-claiming.

The prompt I gave the agent (verbatim)

/Users/xx/Desktop/SCI/单细胞测序/results 这个目录下面有我的乳腺癌癌灶单细胞测序的数据。一共有两个样本。一个是CD 45分选的，一个是没有CD 45分选的。我记不清哪个是哪个了。你帮我分析一下。 08-KLRB1-BRCA_Revised_v2.docx 另外，附件是我的一篇乳腺癌的文章，帮我分析一下，看这个单细胞测序结果能不能支持我的文章结论

Plain language. No JSON scaffold. No "step 1, step 2" instructions. No restrictions on which tools to use. The way I would actually ask a colleague.

Result 1 — Sample identity

The agent ran standard QC + cell-type marker inspection (PTPRC/CD45, CD3E, C1QA, KRT19, COL1A1) on both samples without my telling it which one was sorted. It cross-checked against the QC-filtered composition. Both approaches pointed at the same answer.

SampleVerdictEvidence
THS_2CD45-sortedImmune-cell total 95.7%; PTPRC⁺ rate 71.2%. Tumor-epithelial and stromal markers essentially absent in QC-passed cells.
THS_1UnsortedImmune 34.1%, epithelium 35.1%, fibroblasts 22.7%. Mixed tumor microenvironment as expected.

This is the failure mode I worried about most. The agent did not guess. It picked from the data, named which was which, and showed its work.

Result 2 — Does scRNA-seq support the KLRB1 manuscript?

The agent's verdict: partial support, three of the manuscript's central claims need rewriting.

What the agent confirmed

✓ KLRB1 is a lymphocyte marker in this tumor

KLRB1 expression is concentrated in T/NK lineage cells; epithelial and stromal expression is near zero. CD4⁺ memory T cells have the highest KLRB1⁺ proportion within the T compartment (42.3%). This is consistent with the manuscript's broad framing that KLRB1 biology here is set by the immune compartment.

What the agent pushed back on

✗ "KLRB1 reflects armed cytotoxic infiltration" — not supported at single-cell level

Within individual T/NK cells, KLRB1 expression is essentially uncorrelated with the cytotoxic effectors PRF1, GZMB, and NKG7 (Spearman ρ ≈ 0). The agent then did something I would not have thought to ask for: it re-ran the same correlation after aggregating by (cell type × sample) into pseudo-bulk. Suddenly ρ jumped to 0.73–0.91.

The agent's interpretation: the strong KLRB1-PRF1 correlation seen in bulk data (e.g. TCGA, ρ=0.78) is almost entirely driven by cell-type composition differences, not by KLRB1⁺ cells themselves being high-PRF1 cells. After depth correction, KLRB1⁺ T/NK cells had no detectable difference in PRF1 or GZMB; NKG7 and CD8A were actually lower.

This is the strongest single contribution from the agent on this case — the kind of confounder I would have written the paper around without noticing.

✗ "TIGIT⁺PRF1⁻ activated but inhibited" signature — direction runs the other way

The manuscript's central mechanism: cells near CD4⁺ memory T cells that are KLRB1⁺ show TIGIT up, PRF1 down — read as a brake being applied.

Single-cell co-expression shows the opposite. Within KLRB1⁺ cells, the TIGIT⁺ subset has higher PRF1 positivity (depth-corrected OR=1.75, P=0.005) and higher NKG7 (OR=1.67). TIGIT only correlates with activation markers (NKG7, IFNG) when restricted to the CD4⁺ memory T subset — i.e. it behaves like an activation marker in this dataset, not an inhibitory one.

This doesn't kill the manuscript; it scopes it. The "TIGIT⁺PRF1⁻ brake" claim needs to be qualified to: (a) only valid within the CD4⁺ memory T sub-compartment, and (b) only valid at the spatial-distance level, not the co-expression level.

✗ "CD4⁺ memory T cells as PVR/NECTIN2 ligand source" — not supported

The manuscript's spatial model has CD4⁺ memory T cells providing the TIGIT ligands PVR (CD155) and NECTIN2 (CD112) to nearby cells. The agent checked the expression: PVR 0.34% and NECTIN2 1.81% positivity in CD4⁺ memory T cells. The actual PVR/NECTIN2 sources in this dataset are epithelial tumor cells, myeloid cells, fibroblasts, and endothelium.

If the manuscript wants to keep this part of the mechanism, it needs to be rewritten as an indirect model — CD4⁺ memory T cells induce myeloid / tumor-cell ligand upregulation — rather than a direct ligand-source model.

Other corrections worth noting

△ CLEC2D (LLT1) cellular source attribution

The agent's annotation flagged that CLEC2D in this dataset is primarily expressed by T/NK cells, not by tumor cells as some passages in the manuscript's discussion imply. Worth a targeted edit in the mechanism paragraph.

Writing recommendations I actually used

Five concrete edits I made to the manuscript after this analysis:

  1. Re-positioned the scRNA-seq dataset as case-level landscape description, not a main-conclusion support.
  2. Replaced "KLRB1 reflects NK/CD8 cytotoxic infiltration" with the more neutral: "KLRB1 marks a memory-like T-cell population, with no significant intracellular co-expression with cytotoxic effectors."
  3. Added a caveat to the TIGIT⁺PRF1⁻ signature: valid at the spatial-distance level, with the opposite direction at the co-expression level — suggests TIGIT's inhibitory function here may need protein / functional validation, or is contingent on spatial contact.
  4. Edited the PVR/NECTIN2 ligand-source paragraph: indirect mechanism via myeloid / tumor-cell induction, no longer direct ligand-source from CD4⁺ memory T cells.
  5. Corrected CLEC2D cellular source attribution in the discussion.

What this case taught me about AI agents

  • The most valuable output was the contradiction, not the confirmation. I knew KLRB1 was in lymphocytes. The thing I didn't know was that the manuscript's "KLRB1 reflects cytotoxic infiltration" claim collapses at the single-cell level. That contradiction is the work product.
  • Single-cell co-expression ≠ pseudo-bulk correlation — and a useful agent runs both. If the agent only reports pseudo-bulk ρ, you have no way to know whether you're looking at a real cell-intrinsic association or a composition artifact.
  • Depth correction is not optional. UMI-driven detection bias can manufacture or destroy a "positive" gene signal. Any agent that says "gene X is enriched in cluster Y" without stratifying by depth is selling you noise.
  • An agent that pushes back is more useful than one that agrees. The agent told me three things I didn't want to hear about my own draft. Two of those became edits; one became an additional functional-experiment proposal.

Limitations of this case

  • One patient, two samples. No claim about population-level prevalence of these findings.
  • One agent version. Other agents or older versions may handle the same case differently.
  • scRNA-seq alone cannot resolve spatial-distance claims. The TIGIT⁺PRF1⁻ finding at spatial level is not falsified by this analysis — only by further spatial transcriptomics or functional assays.
  • I cannot publish the manuscript or its specific conclusions here (in submission), only the agent's evaluation of them.
