超市与菜市场手机支付实操

从扫码到付款一学就会，出门不用带钱包。

现在出门买东西，很多人都不带现金了。手机就是钱包：在超市买完东西、在菜市场买菜、在药店买药，手机一扫就能付钱。本教程教长辈三种最常用的手机支付方式。

准备工作：手机上要有微信或支付宝

手机支付主要用到两个软件：微信和支付宝。出门前先确认手机上已经安装了这两个软件，并且里面有足够的钱（绑定了银行卡或者微信/支付宝余额里有钱）。

如果还没安装，请先参考应用下载教程，在应用商店里安装好微信和支付宝。

方式一：出示付款码（超市、便利店使用）

这是最常用的支付方式。你不需要做任何操作，只需把手机上的二维码给收银员扫一下即可。

打开支付宝（或微信）

在手机桌面上找到支付宝或微信图标，点击打开。

找到"付款码"或"收付款"

支付宝：打开后点击首页顶部的"付钱"或"付款码"按钮。
微信：打开后点击右下角的"我" → 点击"支付"（或"服务"） → 点击"收付款"。首次使用需要设置支付密码。

把手机递给收银员扫码

屏幕上会出现一个黑白相间的二维码和条形码，把这个屏幕对着收银员的扫码枪。听到"滴"的一声，就说明支付成功了。

确认支付完成

手机屏幕上会显示"支付成功"以及付款金额。收银员也会给你小票，可以核对一下金额是否正确。

💡 小提示：在超市排队付款时，可以提前打开付款码，这样轮到你了直接递手机就行，又快又方便。付款码每分钟会自动更新，不用担心安全问题。

方式二：扫商家的二维码（菜市场、小摊使用）

这种方式是"你扫老板"，适合菜市场、路边小摊、小店铺等场景。

打开微信或支付宝的"扫一扫"

微信：打开微信，点击右上角的"+"号，选择"扫一扫"。
支付宝：打开支付宝，点击首页左上角的"扫一扫"图标。

对准老板的二维码

老板的摊位前通常会贴着一张打印的二维码，把手机摄像头对准二维码，保持约20厘米的距离，让二维码完整出现在屏幕框内。

输入付款金额

扫描成功后，手机会弹出输入金额的页面。在"金额"栏中输入你要付的钱数（比如买菜15元，就输入15）。

确认并输入密码

核对金额无误后，点击"付款"或"确认支付"，然后输入支付密码（6位数字）。支付成功后手机会有提示。

⚠️ 特别提醒：扫老板的二维码付款时，金额需要自己输入！付钱前一定仔细看屏幕上的数字对不对。有些老人一紧张多输了一个零，比如15元的菜付了150元。付款完成后，可以把付款成功的页面给老板看一眼，证明已经付过了。

方式三：面对面转账（给个人付款）

有时候不是在商店买东西，而是给亲戚朋友、邻居付钱，比如买邻居家的土鸡蛋、给修理工付上门费，可以用"转账"功能。

打开微信，找到对方的聊天窗口

在微信通讯录中找到对方名字，点击进入聊天界面。

点击右下角的"+"号

在聊天输入框的右侧或下方，找到"+"号，点击它。

选择"转账"

在弹出来的菜单中，找到"转账"（是一个红包图标下面写着"转账"），点击进入。

输入金额并付款

输入要转的金额，点击"确认转账" → 输入密码 → "支付成功"。对方收到钱后会有消息提示。

💡 温馨提示：微信转账和发红包的区别：转账金额直接显示在聊天里，红包需要对方点开才知道金额。给长辈转钱建议用转账，方便对方确认数目。

各种场景实操说明

不同场景用不同的支付方式，记住这个简单的规律：

🏪 大型超市

用"出示付款码"。排队快到你时提前打开支付宝或微信的付款码，收银员扫一下就好。

🥬 菜市场

用"扫一扫"。老板会贴一个二维码，你打开扫一扫，输入金额付款。付完给老板看一眼手机。

💊 药店

两种都可以。大药店一般用"出示付款码"，小药店可能用"扫一扫"。

🍜 餐厅/小吃店

大餐厅到前台结账时出示付款码。小饭馆常是"扫一扫"桌面上的二维码。部分餐厅是扫码点餐后直接手机上付款。

🏥 医院

医院收费窗口可以用出示付款码。现在很多医院还支持手机上直接挂号和缴费，不用排队。

🚕 坐出租车

下车时用"扫一扫"扫司机手机或车上的二维码，输入车费金额后付款。

⚠️ 重要提醒：付款时一定看清楚支付金额。先确认再输密码！无论哪种支付方式，都不要在付款前把手机交给别人操作。

安全提醒：手机支付六条"铁律"

  • 付款前必须确认金额无论用哪种方式付款，都要看一眼屏幕上的金额对不对。特别是扫二维码自己输入金额时，多输一个零就亏大了。
  • 不要把自己手机给别人操作有些骗子会假装好心教老人用手机，结果偷偷把钱转走。如果需要帮助，找穿制服的店员或找身边的年轻人帮忙。
  • 不要给陌生人扫码如果有人让你"帮忙扫个码"或者"扫码领礼品"，直接拒绝。这可能是骗局或盗取你的信息。
  • 关闭免密支付建议关闭小额免密功能，每笔付款都输入密码，虽然麻烦一点，但更安全。设置路径：支付宝 → 我的 → 设置 → 支付设置 → 免密支付；微信 → 我 → 支付 → 右上角... → 免密支付。
  • 手机丢失后立即挂失手机丢了要马上用家人手机拨打支付宝客服95188冻结账户，以及微信客服95017冻结支付功能。
  • 不要随便连接免费WiFi付款在商场、超市付款时尽量用手机流量（4G/5G），免费的公共WiFi可能会盗取你的支付信息。

如果付错了怎么办

万一不小心付多了钱，或者付错了人，不要慌张。按照下面的方法处理：

  • 支付宝付错的：打开支付宝 → 点击底部"我的" → 选择"账单" → 找到多付的那一笔 → 点击"联系收款方" → 说明情况协商退款。
  • 微信付错的：打开微信 → 点击"我" → "支付"（或"服务"） → "钱包" → "账单" → 找到该笔交易 → 点击"联系收款方"。
  • 联系不上收款方：拨打支付宝客服电话 95188 或微信支付客服电话 95017，向客服说明情况，他们会协助处理。
  • 如果是被诈骗了：立即拨打110报警，然后联系银行和支付平台客服冻结账户。
💡 最好的办法是防患于未然：每次付款前多看两眼屏幕，确认金额和收款人名字。养成"先确认再输密码"的习惯，比事后补救轻松得多。

建议：设置单日支付限额

为了防止万一，强烈建议长辈设置"单日支付限额"，把每天最多能花多少钱提前定好。建议设置在1000元以内：

支付宝设置：打开支付宝 → 点击右下角"我的" → 右上角"设置" → "支付设置" → "单日限额" → 输入你想要的限额（如1000元）。

微信设置：微信目前不能直接设置限额，但可以在银行卡上设置。联系银行卡的客服或在银行APP中设置"单日消费限额"。

⚠️ 安全提醒：设置限额后，即使手机不小心被他人拿到，对方每天最多也只能花1000元，大大降低了损失风险。等用熟练了或者有大额需求时可以让子女帮忙调高。

常见问题解答

Q：用手机付钱安全吗？会不会被盗刷？

只要做好安全设置就很安全。关键三点：一是设置支付密码（不要用生日或简单数字），二是关闭免密支付功能（每笔都要输密码确认），三是设置单日支付限额（建议1000元以内）。这样即使手机不小心丢了，别人也没法刷走你的钱。

Q：付款码和扫一扫有什么区别？分别在什么场景用？

付款码是你出示二维码给别人扫，适合超市、便利店等正规收银台。扫一扫是你去扫别人的二维码，适合菜市场小摊、小店。简单记忆：去大超市用"付款码"，去小摊用"扫一扫"。

Q：手机没网络能付钱吗？

可以。微信和支付宝都支持"离线码"功能，即使手机没有网络，付款码也能正常使用。但要注意：离线码每分钟会自动更新一次，失效后需要重新获取。建议在外出前提前打开一次支付宝或微信，让付款码加载好。

Q：支付时输错金额多付了怎么办？

不要慌。用支付宝付的，打开支付宝 → 我的 → 账单 → 找到该笔交易 → 点击"联系收款方"协商退款。用微信付的，打开微信 → 我 → 支付 → 钱包 → 账单 → 找到交易 → 联系收款方。如果联系不上，可以拨打官方客服电话：支付宝95188，微信95017。
