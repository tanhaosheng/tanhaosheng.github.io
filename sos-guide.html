手机SOS紧急求助功能设置教程

连按电源键自动呼叫紧急联系人并发送定位。关键时刻能救命的功能，花5分钟设置好，全家都安心。

万一在家摔倒、出门迷路、身体突然不舒服……手机上有一种功能可以在紧急时刻帮您一键求救，它就是 SOS紧急求助。只要连续按电源键（或音量键），手机就会自动给子女或家人打电话、发送当前位置。无论您用的是华为、小米、OPPO、vivo还是苹果手机，都有这个功能。今天这篇文章手把手教您设置好。

一、华为 / 荣耀手机设置SOS

打开"设置"

在手机桌面上找到齿轮形状的"设置"图标，点击进入。

找到"安全"选项

在设置列表中向下滑动，找到"安全"（有的手机也叫"安全和隐私"），点击进入。

点击"SOS紧急求助"

在安全设置中，找到"SOS紧急求助"或"紧急求助"，点击进入。

开启"连按电源键发起紧急呼叫"

把开关打开（变成蓝色/绿色）。部分手机会弹出提示说明，点击"同意"。

设置紧急联系人

点击"紧急联系人"，选择"从通讯录添加"，勾选子女或家人的电话号码。可以添加多位联系人（建议至少2位）。

开启"自动发送求助信息"

将"自动发送求助信息"开关打开。这样发起求救后，手机会自动向联系人发送当前位置短信。

温馨提示：华为手机还可以设置"紧急通知倒计时"，建议设为3秒。这样如果不小心误触，可以在倒计时结束前取消。

二、小米 / 红米手机设置SOS

打开"设置"

从手机桌面找到"设置"图标并点击。

找到"安全"或"密码与安全"

在设置列表中向下滑动，找到"安全"或"密码与安全"选项。

点击"SOS紧急求助"

在安全设置中找到"SOS紧急求助"或"紧急求助"。

开启"紧急求助功能"

将顶部的总开关打开。系统会提示授权，点击"允许"。

添加紧急联系人

点击"紧急联系人" → 点击"添加" → 从通讯录中勾选家人。小米手机最多可以添加5位联系人。

设置触发方式

选择"连按电源键5次"触发紧急呼叫。同时可以开启"自动发送位置信息"和"自动拨打求助电话"。

注意：小米手机默认触发方式是连按电源键5次，建议让长辈多练习几次，确保在紧急情况下能按对。

三、OPPO / 一加手机设置SOS

打开"设置"

在手机桌面上找到"设置"图标并点击。

进入"安全"设置

在设置中找到"安全"选项（部分机型叫"密码与安全"）。

选择"SOS紧急联络"

在安全设置中找到"SOS紧急联络"或"紧急求助"。

开启"连按电源键紧急呼叫"

将开关打开。OPPO手机会提示"连按5次电源键"触发的说明，点击"知道了"。

设置紧急联系人

点击"紧急联系人" → 点击右上角的"+"号 → 从通讯录中选取家人。可以添加多位。

开启"自动发送求助信息"

将"自动发送位置信息"和"自动拨打电话"都打开，这样SOS时会同时打电话和发短信。

温馨提示：OPPO手机设置完成后，可以在"SOS紧急联络"页面点击"使用演示"来测试功能，不会真的打电话，可以放心操作。

四、vivo手机设置SOS

打开"设置"

在手机桌面找到并点击"设置"。

找到"安全与隐私"

在设置列表中滑动，找到"安全与隐私"选项。

点击"SOS紧急求助"

在安全设置中找到"SOS紧急求助"并点击进入。

开启"连按电源键紧急呼叫"

将开关打开。vivo手机会有倒计时提示，点击"确认"。

添加紧急联系人

点击"紧急联系人" → 点击"添加联系人" → 从通讯录中选择家人。建议至少添加2~3位。

开启"发送定位信息"

将"发送当前位置"和"呼叫紧急联系人"两个选项都打开，确保家人能第一时间知道您的位置。

五、iPhone设置SOS（苹果手机）

打开"设置"

在iPhone桌面上找到灰色的齿轮图标"设置"，点击进入。

找到"SOS紧急联络"

在设置列表中找到"SOS紧急联络"选项（通常在"面容ID与密码"下方）。

开启"按5次电源键呼叫"

将"用按按钮呼叫"或"连按5次电源键"开关打开。部分系统版本叫"按住再松开"。

设置"紧急联系人"

在"健康"App中设置紧急联系人。回到桌面 → 打开"健康"应用（白色背景，粉红色心形图标） → 点击右下角的"个人资料" → 选择"医疗急救卡" → 点击"编辑" → 在"紧急联系人"处点击"添加" → 从通讯录中选择家人。

开启"发送紧急求助信息"

在SOS设置中，确保"发送紧急求助信息"或"呼叫后发送信息"开关打开。这样SOS后会自动向联系人发送位置信息。

特别提醒：iPhone的SOS功能触发后，手机会自动拨打本地紧急号码（如110、120），然后才联系您的紧急联系人。建议在子女陪同下熟悉流程。

六、测试SOS功能是否正常

设置完成后，一定要测试一次。让长辈知道触发后是什么感觉，也确认联系人能收到求助信息。以下是推荐的安全测试方法：

提前告知紧急联系人

先给子女或家人打个电话："我要测试手机SOS功能，等会儿你会收到一条测试短信，别紧张。"

按电源键触发SOS

按照您手机品牌的触发方式，连续按电源键（一般是5次）。如果手机弹出倒计时，等待倒计时结束。

等待呼叫并及时挂断

手机自动呼叫紧急联系人。接通后可以说"这是测试，已经成功了"，然后挂断。如果不想真的拨打，部分手机在倒计时期间可以点击"取消"。

确认家属收到定位短信

请家人检查手机是否收到了包含您位置信息的短信。如果有，说明定位功能也正常工作了。

测试后关闭或重置

部分手机测试后需要重新锁定屏幕才能再次触发SOS，建议测试后帮长辈锁屏再解锁一次，恢复正常状态。

重要建议：建议每半年测试一次SOS功能。特别是长辈换了新手机、系统升级后，务必重新检查和测试。

七、日常提醒：避免误触与取消方法

设置好SOS功能后，长辈可能会担心"万一不小心碰到了怎么办？"请放心，所有手机在触发SOS后都有取消的方法。请教会长辈以下操作：

误触取消方法：如果不小心触发了SOS功能，在倒计时期间（一般是3~5秒），手机屏幕会显示倒计时数字。此时点击屏幕上的"取消"或"停止"按钮，即可取消呼叫。有些手机需要滑动滑块取消。如果倒计时结束已经开始呼叫，直接按一下电源键挂断电话即可，然后给家人发个消息说"刚才是误触，没事"。
日常注意事项：
  • 手机放口袋时注意不要让电源键长时间被挤压（建议手机屏幕朝外放口袋）
  • 如果设置了指纹或人脸解锁，建议同时保留锁屏密码
  • 教会长辈：万一误触拨出了SOS，接通后说一句"对不起，按错了"即可，不用尴尬

八、常见问题（FAQ）

Q：误触了SOS功能怎么办？会不会让家人很担心？

A：保持冷静。如果呼叫还没有接通，点击屏幕上的"取消"或"停止"即可。如果已经接通，直接告诉家人"不好意思，不小心碰到了"。建议让家人把您的紧急联系人备注改为"紧急联系人-儿子"等，这样他们接到电话时能第一时间识别。长期来看，可以在手机上设置更长的触发倒计时（3~5秒），减少误触概率。

Q：换了新手机之后，SOS需要重新设置吗？

A：需要！换新手机后，所有数据都不会自动迁移。请按照本文对应品牌的设置步骤，在新手机上重新设置SOS紧急联系人和触发方式。同样，手机系统大版本更新（比如从Android 13升级到Android 14）后，也建议检查一下SOS设置是否被重置。简单说就是：换手机必重新设置，系统升级必检查一遍。

Q：我在国外能用SOS功能吗？怎么联系紧急服务？

A：不管在哪一个国家和地区，所有正规品牌手机（华为、小米、OPPO、vivo、iPhone等）的SOS功能都可以使用。在国外触发SOS时，手机会自动拨打当地的紧急号码（比如在美国拨打911，在日本拨打110/119/119）。同时，您设置的家人紧急联系人也会收到电话和定位短信。建议长辈出境旅游前，子女帮长辈检查SOS功能是否正常。

Q：设置了SOS，但按电源键没反应怎么办？

A：首先确认是否已经完成了完整设置（不只是打开开关，还要添加紧急联系人）。部分手机需要在锁屏状态下才响应SOS触发，请先锁屏再尝试。如果还是不行，可以尝试以下方法：
① 重启手机后再试一次；
② 检查手机系统是否有更新，更新到最新版本；
③ 前往手机品牌的"设置 → 搜索"中输入"SOS"直接搜索；
④ 仍然不行的话，可以让子女帮您查找该品牌手机的客服电话咨询。

给子女的建议：帮长辈设置好SOS后，建议在自己的手机里把长辈的来电铃声设置为特殊的铃声（比如救护车声音或明显的警示音），这样万一长辈触发SOS，您能第一时间注意到手机来电，尽快接听。
