## 域名折腾记录

### 购买的域名
- tanhaosheng.asia（腾讯云购买，已弃用）

### 尝试过的方案
1. ✅ GitHub Pages 默认域名（tanhaosheng.github.io）
2. ❌ 腾讯云DNS指向GitHub Pages（A记录限制2条）
3. ❌ Cloudflare DNS + GitHub Pages（配置复杂）
4. ❌ Cloudflare Pages Direct Upload（DNS切换失败）
5. ❌ 自定义域名 tanhaosheng.asia（最终放弃）

最终决定放弃自定义域名，退回使用 tanhaosheng.github.io。

### 经验教训
- CNAME文件会导致GitHub Pages自动切换到自定义域名
- GitHub Pages在国内访问不稳定
- Cloudflare DNS切换NS需要时间传播
- 腾讯云免费DNS套餐限制A记录数量
- `<\/script>` 转义错误会导致页面空白，Python脚本中写入 `</script>` 时要用 `</` + `script>` 避免字符串提前闭合
- 修改文件后必须重新部署到GitHub才能生效，本地修改不影响线上
- GitHub Pages设置中的Custom Domain与仓库中的CNAME文件会互相影响，一个改了另一个也必须同步改
- 多个平台间（腾讯云DNS、Cloudflare、GitHub Pages）配置切换时容易出现配置残留，建议一次只用一个方案

## 经验教训汇总
- CNAME文件会导致GitHub Pages自动切换到自定义域名，必须同时清除GitHub设置中的Custom Domain
- GitHub Pages在国内访问不稳定，国内用户建议使用CODING Pages或云服务器
- Cloudflare DNS切换NS需要5~30分钟传播时间
- 腾讯云免费DNS套餐限制A记录数量（3条上限）
- 腾讯云显性URL转发需要域名ICP备案，未备案不可用
- `<\/script>` 转义错误会导致页面空白，Python脚本中写入 `</script>` 时需注意转义
- 修改本地文件后必须重新部署到GitHub才能生效
- 多个平台间（腾讯云DNS、Cloudflare、GitHub Pages）配置切换时容易出现配置残留，建议一次只用一个方案
- Cloudflare的页面规则（Page Rules）免费版可做301跳转，不需要备案
- 手机开热点可以上外网访问Cloudflare控制台

## Cloudflare 301 跳转配置（2026-07-25 成功配置）

### 目标
将 tanhaosheng.asia 301 跳转到 tanhaosheng.github.io，使 .asia 域名的访问量计入主站，增加 AdSense 收入。

### 配置步骤

#### 1. 在 Cloudflare 添加站点
- 登录 https://dash.cloudflare.com/
- 点击"添加站点" → 输入 tanhaosheng.asia
- 选择 Free（免费计划）
- 获取两个 Cloudflare Nameserver 地址

#### 2. 在腾讯云修改 DNS 服务器
- 打开 https://console.cloud.tencent.com/domain
- 点击 tanhaosheng.asia → "DNS 服务器"
- 将 DNSPod 的 NS 改为 Cloudflare 的 NS：
  - `dora.ns.cloudflare.com`
  - `emerson.ns.cloudflare.com`
- 等待生效（约 5~10 分钟）

#### 3. 在 Cloudflare 添加 DNS 记录
左侧菜单 → DNS → 添加记录：
| 类型 | 名称 | 值 | Proxy |
|------|------|-----|-------|
| A | @ | 192.0.2.1 | ☁️ 橙色(Proxied) |

#### 4. 在 Cloudflare 创建页面规则
左侧菜单 → 规则 → 页面规则 → 创建页面规则：
| 项目 | 填写内容 |
|------|---------|
| URL | `tanhaosheng.asia/*` |
| 设置 | 转发 URL |
| 转发类型 | 301 - 永久重定向 |
| 目标 URL | `https://tanhaosheng.github.io/$1` |

### 验证结果
```bash
curl -sI https://tanhaosheng.asia/
# HTTP: 301
# Redirect: https://tanhaosheng.github.io/
```

### 注意事项
- 腾讯云显性URL转发需要域名ICP备案，未备案不能用
- Cloudflare 的页面规则（Page Rules）免费版可用
- 301 跳转对 SEO 友好，搜索引擎会将权重转移到目标域名
- 修改 NS 后需要等待 DNS 传播（几分钟到几小时）
- `.asia` 域名已不再直接托管网站内容，仅做跳转
