## 域名折腾记录

### 购买的域名
- tanhaosheng.asia（腾讯云购买，已弃用）

### 尝试过的方案
1. ✅ GitHub Pages 默认域名（tanhaosheng.github.io）
2. ❌ 腾讯云DNS指向GitHub Pages（A记录限制2条）
3. ❌ Cloudflare DNS + GitHub Pages（配置复杂）
4. ❌ Cloudflare Pages Direct Upload（DNS切换失败）
5. ❌ 自定义域名 tanhaosheng.asia（最终放弃）

最终决定放弃自定义域名，退回使用 tanhaosheng.github.io。

### 经验教训
- CNAME文件会导致GitHub Pages自动切换到自定义域名
- GitHub Pages在国内访问不稳定
- Cloudflare DNS切换NS需要时间传播
- 腾讯云免费DNS套餐限制A记录数量
