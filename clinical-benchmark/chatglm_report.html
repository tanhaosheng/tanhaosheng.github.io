框架 v1.0 · 乳腺癌术后病例解读 + 后续辅助治疗建议 · 参考 2026 CBCS Version 2026.1.0 · 含与 DeepSeek 快速模式对比

⚠️ 两个独立硬伤（先于评分）：
① 三段全部英文回答。输入 Prompt 与病历均为中文，但 GLM 5.2 三跑均输出英文（截图与文字版均确认）——对中文临床用户的可用性几乎为零，且意味着模型未真正"吃透"中文医学语境。
② 三跑内容极短极泛。基本模式是"复述病历 + 泛泛建议 + 免责声明"，几乎没有真正展开临床决策推理。

  • DeepSeek（网页快速模式）：https://chat.deepseek.com/ —— 对比模型，实测详见 deepseek_report.html。

四、ChatGLM 的两大独立硬伤

① 全部英文输出（可用性硬伤）
输入是中文 Prompt + 中文病历，三段回答均为英文。对中文临床用户意味着： - 阅读/复核成本高（临床要逐字对照术语）； - 中文指南引用、术语翻译、剂量写法可能丢失/错译； - 等于把决策权交给一个"未用你的语言思考"的模型。
临床场景下不可接受，无论评分高低。
② 极低信息密度 + 高度不稳定（质量硬伤）
三段平均字数约 130 字（DeepSeek 约 450 字），几乎没有具体临床决策；Run 2 只有 2 分（几乎只是复述病历 + "建议医生决定"）。 三跑 spread = 8，触发框架"≥8 分判定为不稳定"阈值，意味着同一任务重复提问结果不可预期。

五、最终建议（框架 §6）

综合排名

DeepSeek 快速模式 ≫ ChatGLM 5.2，在所有可比维度上 DeepSeek 都更强，且 DeepSeek 是中文输出可直接临床复核。

对临床场景的实用结论

任务类型推荐理由
中文临床决策推理（如本例）DeepSeek 快速中文输出、信息密度高、稳定可复现
快问快答 / 用药常识DeepSeek 快速秒回、大方向不翻车
需要引用具体指南章节两者均不可引用准确率都是 0/16
分期再判读 / 推荐等级微调两者均不可单独采信核心题双双失分，且都"自信"地不质疑出院诊断
英文医学文献阅读 / 国际指南可考虑 ChatGLM英文输出对国际资料阅读反而是优势（但本次任务未涉及）
✅ 结论一句话： 在"中文 + 临床决策推理 + 0 成本"这个三角里，DeepSeek 快速模式完胜 ChatGLM 5.2。两个模型都还达不到临床可单独采信的门槛，但 DeepSeek 至少给了"虽错但深"的推理链可核对；ChatGLM 给的是"泛泛 + 免责声明"，既无核对价值也不适合中文医生日常使用。

数据局限：仅 1 例、仅文字输入、仅免费档、每模型 3 次。本报告为内部 LLM 选型评估，不构成任何临床建议。 ChatGLM 三段完整原文：chatglm_answers.html。 DeepSeek 三段完整原文：deepseek_answers.html。
