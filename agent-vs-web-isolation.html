Same Model, Three Wrappers: 3 Models, 9 Runs, 1 LVI Read — Hands-on Review 3 of 5

By Tan Haosheng · 副主任医师 / 医学博士 (Associate Chief Physician, MD/PhD) · 甲状腺乳腺外科 (Thyroid & Breast Surgery), 泰州市人民医院 (Taizhou People's Hospital) · Published 2026-07-30, updated 2026-07-31
🧪 原创实测 #3 / 5  ·  Hands-on Review 3 of 5 — Web vs Agent isolation (now 7 models ranked, web side still pending for the agent trio)
Why this follow-up exists: In Part 2, DeepSeek V4 Pro wrapped in the WorkBuddy agent scored 50/100 — the only model to catch the staging trap. But that score conflates two things: the model and the wrapper (system prompt, tool/MCP context, formatting expectations). Was the WorkBuddy agent helping the model, or was V4 Pro simply that good on its own? This article starts answering that question by testing DeepSeek V4 Flash and Kimi K3 through the WorkBuddy agent, plus Grok 4.5 fast through the simpler X.com built-in wrapper, on the same fresh case. The web-version runs for the agent trio — which will tell us the answer to "is the wrapper doing the work?" — are still pending.

The question Part 2 left open

Part 2 compared different models on the same case and ranked them by score. That tells us which model to use, but not why it ranked where it did. The wrapper confound is real:

  • WorkBuddy ships with a structured clinical-style system prompt (Chinese, asks for staged reasoning, table outputs).
  • DeepSeek web "fast mode" gives a much shorter, more chatty answer.
  • ChatGLM web default answers in English even on Chinese prompts.

If V4 Pro wins only when wrapped, the wrapper matters clinically and we should design around it. If V4 Pro wins even raw, it's the model and we can pick the cheapest interface.

Methodology (lighter than Part 2)

I simplified the prompt on purpose. Instead of a 16-item structured question (Part 2), this test uses one anonymized case-report image plus the prompt "Next therapy ?" — closer to what a clinician or patient actually types. Same image, same prompt, three runs per (model × wrapper) cell. Scoring stays consistent: correct + cited specific guideline section = full points; correct but uncited = half; wrong = 0.

This article scores 10 decision points against the 2026 CBCS / CSCO 2024 / NCCN 2025 consensus. The weights sum to 100.

The case (a different one from Part 2)

Anonymized real post-op breast cancer case:

  • Patient: 60-year-old, postmenopausal.
  • Surgery: Right simple mastectomy + sentinel lymph node biopsy (with one para-sentinel node).
  • Pathology: Invasive ductal carcinoma + DCIS + intraductal papillary carcinoma components; largest invasive focus 0.6 cm; lymphovascular invasion (LVI) in 3 foci (0.05 / 0.06 / 0.2 cm); ER 3+ 90%, PR 3+ 90%, HER2 0, Ki-67 5%, P53 wild-type; margins, nipple, skin, base all negative.
  • Nodes: 0/2 sentinel + 0/1 para-sentinel = 0/3 negative.
  • Contralateral: Fibroadenoma + adenosis + sclerosing adenosis (benign, follow-up only).
  • Correct stage & subtype: pT1bN0M0, Stage IA, Luminal A-like. (Note: this case is NOT the same as Part 2's 0.2 cm / Tis trap; direct cross-case score comparison requires caveat.)

Reference answer (2026 CBCS / CSCO 2024 / NCCN 2025)

  • Endocrine therapy — Aromatase inhibitor (letrozole 2.5 mg / anastrozole 1 mg / exemestane 25 mg, daily) for ≥ 5 years; extend to 7–10 years because LVI is present (MA.17R, NSABP B-42, ATLAS/aTTom evidence).
  • Chemotherapy — Not routinely indicated (T1b, N0, Luminal A-like, postmenopausal, Ki-67 5%); Oncotype DX may be ordered for shared decision-making but not required.
  • Post-mastectomy radiation therapy (PMRT) — Not indicated (T1–2N0 mastectomy; LVI alone is not an indication per CSCO/NCCN/ASTRO).
  • Anti-HER2 therapy — Not indicated (HER2 IHC 0).
  • Bone protection — Bisphosphonate (zoledronic acid 4 mg IV q6m × 3 years) or denosumab while on AI (ABCSG-12 / AZURE).
  • Follow-up — Standard 3–6 month clinic visits, annual contralateral breast imaging, BMD every 1–2 years on AI.

DeepSeek V4 Flash via WorkBuddy agent — 3 runs

Same image, same "Next therapy ?" prompt, three independent runs. All three answered in Chinese.

Run 1 — strong

Staged the case correctly as pT1bN0M0 (IA), called it Luminal A, flagged the 3 foci of LVI as a high-risk feature, recommended letrozole 2.5 mg qd × 7–10 years, said "no chemo, no radiation, no targeted therapy", prescribed zoledronic acid 4 mg IV q6m × 3 years explicitly. Cited CSCO 2024, NCCN, ATLAS / aTTom, ABCSG-12 / AZURE, EBCTCG meta. Included a patient-education block. Most clinically complete of the three runs.

Run 2 — partial, with a staging slip

Staged the case as pT1aN0(sn)M0 — that is wrong for a 0.6 cm invasive focus. (pT1a is ≤ 5 mm; pT1b is > 5 mm but ≤ 10 mm. A 0.6 cm / 6 mm focus is T1b, not T1a.) On the other hand, Run 2 was the only run to explicitly call out the original record's "TisN0M0 Stage 0" line as a transcription error — that is the same kind of trap as in Part 2, and the model caught it. Luminal A correct, AI correct, chemo / RT / HER2 correctly rejected, bisphosphonate mentioned but framed as optional. Cited NCCN / CSCO and "Stewart score" for low-risk classification.

Run 3 — strong

Staged the case correctly as pT1bN0M0 (IA), noted "Tis" referred to the DCIS component (not the invasive stage), Luminal A-like correct, AI 5–10 years with MA.17R / NSABP B-42 / IDEAL evidence, no chemo with TAILORx / RxPONDER citation, no RT with MA.20 / EBCTCG citation, bone health monitoring described but bisphosphonate not explicitly prescribed. Clean, well-cited, clinically defensible.

What the three runs show

  • Two out of three runs got the staging right (pT1b); one mis-staged as pT1a.
  • The model recognized Luminal A biology and postmenopausal endocrine route in all 3 runs.
  • Two out of three recommended bisphosphonate (or "consider"); one only described bone monitoring.
  • LVI was handled inconsistently: Run 1 made it central, Run 2 noted it briefly, Run 3 buried it under DCIS.
  • Guideline citations are by name (CSCO / NCCN / St. Gallen) — no specific section or page numbers in any of the three runs. Same pattern as Part 2 across all four models.

Second leg — Kimi K3 via the WorkBuddy agent, 3 runs (same case, same prompt)

To test whether the agent wrapper helps a different model family, I also ran Kimi K3 (Moonshot AI) — a flagship model reported at ~2.8 trillion parameters (2.8T) — through the same WorkBuddy agent on the same image and the same "Next therapy ?" prompt. Three independent runs. Spoiler: even at that scale, it still failed on the exact step V4 Flash nailed.

The 2.8T irony: Kimi K3 is one of the largest publicly-discussed models by parameter count. And yet, on the very same image where DeepSeek V4 Flash (a smaller model) correctly flagged the 3-focus LVI, Kimi K3 mis-read it as three tiny invasive foci in all three runs. Raw scale did not buy reliability on a clinical image. The failure is in vision / parsing, not in medical knowledge — and no amount of parameters patches a mis-read input.

Run 1 — clinically complete but with one critical mis-read

The headline issue: The model read the pathology as "3 簇间质浸润 (0.5 / 0.6 / 2mm)" and tagged the case as pT1aN0(sn)M0, IA. The original report says "浸润灶 0.6 cm, 脉管瘤栓 3 灶 (0.05 / 0.06 / 0.2 cm)" — the 0.05 / 0.06 / 0.2 cm numbers describe lymphovascular invasion, not three additional invasive foci. A 2 mm invasive focus would be pT1a; a 0.6 cm invasive focus with separate 3-focus LVI is pT1b plus an LVI flag. Kimi K3's run conflated the two, collapsed three tiny LVI foci into one invasive measurement, and lost the LVI flag in the process.

What it still got right: Luminal A-like correct, AI (letrozole / anastrozole / exemestane) as first-line for a postmenopausal patient, explicitly rejected chemo, radiation, anti-HER2, bisphosphonate discussion only at the "monitor BMD + Ca + VitD" level (no actual drug named), follow-up plan included. Cited CSCO / NCCN / CBCS / St. Gallen by name. No specific section.

Run 2 — same mis-read, same LVI omission

Re-stated the same incorrect breakdown: "3 簇间质浸润(约 0.5 / 0.6 / 2mm), 总径 0.6cm" — three invasive foci (the third highlighted as 2 mm), then a 0.6 cm "total" that does not actually add up to the 0.5 + 0.6 + 2 mm series. Staged as pT1a again. Then, like Run 1, recommended AI × 5 years without the 7–10 year extension that the LVI flag would justify. Luminal A correct, chemo / RT / anti-HER2 / CDK4/6 / 21-gene all correctly excluded. Bone monitoring + Ca + VitD; no bisphosphonate. Cited CSCO / NCCN / CBCS / St. Gallen by name. Added a sentence on BRCA testing (not strictly required at this risk level — minor over-call but not harmful). Stated "10-year disease-specific survival ≈ 100%".

Run 3 — same mis-read, same LVI omission

Structurally nearly identical to Run 2: same incorrect "3 簇 0.5 / 0.6 / 2mm" reading, same pT1a staging, same AI × 5 years without LVI-extension justification, same Luminal A correct, same correct rejections (chemo / RT / anti-HER2 / CDK4/6 / 21-gene), same "monitor BMD + Ca + VitD" bone plan without a bisphosphonate prescription, same guideline-name-only citations.

The three Kimi K3 runs are near-clones of each other. That consistency on a wrong read is itself diagnostic: the model is not "thinking out loud" — it has a single stable (and wrong) interpretation of the pathology block.

What the Kimi K3 runs add to the picture

  • Same wrapper, weaker result than V4 Flash. Kimi K3 (agent) median 27 vs V4 Flash (agent) median 34 on the same case, same wrapper. The wrapper is not rescuing a weaker model — the model itself carries most of the variance.
  • Parameter count did not save it. Kimi K3 is reported at ~2.8 trillion parameters — a flagship-scale model — yet it collapsed the LVI read in all 3 runs. This is the clearest evidence in the series that scale alone is not the variable that buys clinical-image reliability. The error lives in image parsing, upstream of whatever the model "knows".
  • LVI is a real read-the-image failure, not a knowledge failure. The guideline knowledge is there ("pT1mi / pT1a N0 HR+ → endocrine alone is enough") — the failure is upstream, in image parsing, where three small numbers were mis-bucketed as invasive instead of LVI. The model never had the chance to apply the 7–10 year extension rule because the trigger event was lost at the read step.
  • Run consistency is high. Three near-identical outputs (one moderate-length, two longer but structurally similar) suggest a confident, low-temperature generation — the model is sure of its mis-read.
  • Same "no specific section" pattern. Kimi K3 also cites guideline names only, no page / section. This is now the third model in the series with that exact weakness.

Third leg — Grok 4.5 fast via X.com (Grok's built-in wrapper), 3 runs (same case, same prompt)

To test a third model family — and a foreign-frontier model that explicitly markets "real-time web + reasoning" — I also ran Grok 4.5 fast (the version embedded directly inside X.com / Twitter, in its default Fast mode) on the same anonymized image, the same "Next therapy ?" prompt, three independent runs. Note: Grok answered in English even though the case image and the user are Chinese — a behavior worth flagging on its own. The headline finding is harsher than Kimi K3's: Grok down-staged a confirmed invasive ductal carcinoma with 3-focus LVI to Stage 0 / TisN0M0 in all three runs.

The Stage-0 collapse. The original report clearly states "浸润灶 0.6 cm, 脉管瘤栓 3 灶 (0.05 / 0.06 / 0.2 cm)" — a 6 mm invasive ductal carcinoma (pT1b) with separate lymphovascular invasion. Grok in all three runs re-classified the case as TisN0M0 / Stage 0 (Run 1: "very early, favorable"; Run 2: "very early, excellent prognosis"; Run 3: "pTisN0M0 (or very early microinvasive pT1miN0) — very low-risk disease"). That is a one-stage down-shift of an invasive cancer. The 3-focus LVI is silently absorbed into the "small focus" framing and disappears from the staging — and therefore from the AI-extension decision.

Run 1 — Tamoxifen (wrong endocrine for a 60-year-old)

Stage-0 read. Opened with "Right breast cancer, stage TisN0M0 (Stage 0) — very early, favorable". Endocrine was correctly chosen as the main next step, but the recommended drug was Tamoxifen — a suboptimal first choice for a 60-year-old postmenopausal patient (NCCN / CSCO 2024 prefer an aromatase inhibitor in this setting). Radiation / chemo / anti-HER2 were all correctly rejected. No bisphosphonate discussion. Follow-up plan mentioned but no bone-density monitoring framed as a concrete protocol. Cited NCCN, Oncotype DX, and a generic "Chinese Breast Cancer guidelines" reference — all by name only, no specific section. Run 1 closed by name-checking "Nanjing Medical University Affiliated Taizhou People's Hospital" and the patient's local oncologist — a courtesy that does not substitute for a guideline citation.

Run 2 — Tamoxifen 20 mg, same Stage-0 framing

Same Stage-0 read. Re-stated the same mis-staging: "TisN0M0 (Stage 0) — very early, excellent prognosis". Recommended Tamoxifen 20 mg daily × 5 years (the same postmenopausal-suboptimal choice as Run 1). Correctly excluded chemo, HER2-targeted therapy, and post-mastectomy radiation. Did mention bone-density monitoring because endocrine therapy can affect bones — but again, no bisphosphonate prescription, just a watch-and-see line. Cited NCCN / Chinese guidelines by name, no page or section. Added an "Oncotype DX may be ordered…" sentence — not strictly required at this risk level, but defensible as shared-decision-making. Run 2 also closed by directing the patient to her treating team at the local hospital.

Run 3 — AI at last, but still on a Stage-0 stage

Half-good: AI choice, wrong stage. Run 3 was the only Grok run to actually pick the correct first-line endocrine for a postmenopausal patient: "Anastrozole (Arimidex) 1 mg daily or Letrozole (Femara) 2.5 mg daily". That is the only fully-correct item in any of the three Grok runs. But the staging was still wrong: "pTisN0M0 (or very early microinvasive pT1miN0) — very low-risk disease". Because the model never recognized the 0.6 cm invasive focus + 3-focus LVI as a true pT1b + LVI, the AI duration is set at the generic "5 years" with no LVI-driven extension, and the bisphosphonate question never gets raised. Cited NCCN / CBCS guidelines, mentioned genomic tests (Oncotype DX) and the "luminal A-like profile" language — but again by guideline name, never with a specific section / page.

What the three Grok runs add to the picture

  • Grok 4.5 fast is the worst-scoring model in the series so far. Three runs, median 14 / 100 (R1 14 / R2 14 / R3 24). The model that explicitly markets "real-time web + reasoning" and is integrated into one of the world's most-used consumer products finished below Kimi K3 (27) and below V4 Flash (34) on the same case, same prompt, three runs each.
  • Stage down-shift is the new failure mode. Kimi K3's failure was an LVI-vs-invasion parsing error that left pT1a (off-by-one). Grok's failure is a stage down-shift — collapsing a pT1b invasive cancer with LVI into TisN0M0 / Stage 0. That is a more dangerous failure pattern: a clinician or patient who reads "Stage 0" and skips the LVI-driven 7–10 year AI extension has undertreated a high-risk feature.
  • Postmenopausal endocrine pick is unstable. Two of three Grok runs picked Tamoxifen (the premenopausal-or-not-stated default); only Run 3 picked the correct AI. That is a real safety gap for any postmenopausal patient who relies on Grok for a hormonal-therapy recommendation.
  • English-only output on a Chinese patient case. All three Grok runs answered in English even though the case image, the user prompt, and the patient are Chinese. Kimi K3 and V4 Flash answered in Chinese. For a Chinese breast cancer patient, the language choice alone makes the answer harder to use and easier to misread.
  • Wrapper does not seem to be the differentiator either. Grok's built-in X.com wrapper is a clean chat interface, similar in spirit to chat.deepseek.com or kimi.com. It is not the long clinical-style system prompt the WorkBuddy agent uses. If anything, that simpler wrapper should have removed the LVI "long answer" pressure — yet the model still lost the LVI in 3/3 runs. This further weakens the "agent wrapper hides the model's reading weakness" hypothesis: the model is the constant; the LVI-read is the variable.
  • "Specific guideline section" weakness now confirmed across four model families — DeepSeek V4 Pro, DeepSeek V4 Flash, Kimi K3, and Grok 4.5 fast all cite guideline names but never page / section / table numbers. This is now a pattern, not an outlier.

Preliminary conclusions (with the obvious caveat that web data is missing)

What this leg already tells me

  • V4 Flash (WorkBuddy agent) is consistent — two of three runs are clinically usable as-is; the third has a T1a/T1b slip but still gives a defensible plan.
  • V4 Flash (WorkBuddy agent) is more stable than V4 Pro (WorkBuddy agent) — V4 Pro had a refusal and a dangerous radiation recommendation across its three runs (Part 2). V4 Flash gave no refusals and no dangerous recommendations.
  • Kimi K3 (WorkBuddy agent) — the wrapper is not the differentiator, and neither is scale. Same wrapper, weaker model, lower score (27 vs V4 Flash's 34). Kimi K3 is a ~2.8-trillion-parameter flagship — and it still lost the LVI flag in 3/3 runs. The wrapper is the constant; the model is what varies the result.
  • Grok 4.5 fast (X.com built-in) — the wrapper is even simpler, the result is even worse. Median 14 / 100, lowest of any model in the series so far. Three different models in three different wrappers (V4 Flash agent, Kimi K3 agent, Grok built-in X.com) all failed the LVI read on the same case. The model is the variable; the wrapper is the constant.
  • Stage down-shift is a new failure mode, and it is dangerous. Kimi K3 down-staged by one bucket (pT1b → pT1a). Grok down-staged by two buckets (pT1bN0M0 IA → TisN0M0 Stage 0) in 3/3 runs. A "Stage 0" label on a confirmed pT1b invasive cancer is not a soft error — it is a clinical misread that removes the LVI-driven AI extension from the conversation entirely.
  • Postmenopausal endocrine pick is unstable across runs. Two of three Grok runs picked Tamoxifen (the premenopausal-or-not-stated default) for a 60-year-old postmenopausal patient. Only Run 3 picked the correct AI. For any patient who relies on a model for hormonal-therapy selection, that is a real safety gap.
  • LVI is a read-the-image failure, not a knowledge failure. Kimi K3 and Grok both clearly know the relevant guidelines (their chemo / RT / HER2 rejections are textbook). They lost the LVI flag at the image-parsing step and never recovered. A better wrapper cannot fix that — a better image-recognition front-end might.
  • The "specific guideline section" weakness is now confirmed across four model families — DeepSeek V4 Pro, DeepSeek V4 Flash, Kimi K3, and Grok 4.5 fast all cite guideline names but never page / section / table numbers. This is now a pattern across every model in the series.

What I cannot say yet

  • I cannot yet isolate the wrapper effect (rank the same model in two wrappers) until web runs land for V4 Flash / V4 Pro / Kimi K3. The 7-model leaderboard above ranks different models across two cases — useful for "which model," not yet for "how much the agent adds."
  • I cannot say "the agent adds 10 / 20 / X points" because we have no same-model / different-wrapper comparison for those three.
  • I cannot claim any of these models is "the best free option" — the case is different and the rubric is different.
  • Grok's "Fast" mode is the cheapest of its three modes; if anything, "Think" or "Deep Research" might do better. Until those are run, Grok is represented here by its cheapest public surface only.
一句话结论（中文）： 同一个病例、同样一句 "Next therapy?"，本次共 3 个模型 / 9 次实测：DeepSeek V4 Flash 智能体 3 次中位 34 / 100（2/3 临床可用，1 次把 0.6cm 误判为 pT1a），Kimi K3 智能体 3 次中位 27 / 100（3/3 都把 0.05/0.06/0.2cm 的脉管瘤栓误读为 0.5/0.6/2mm 的 3 簇浸润灶，因而漏掉 LVI 延长 AI 时长的指征），Grok 4.5 fast（X.com 内置 Fast 模式）3 次中位 14 / 100（3/3 都把 pT1b 浸润性癌 + 3 灶 LVI 错降为 TisN0M0 / Stage 0——这是三个模型里最危险的误读，等于把 IA 期直接降成 0 期，连带把"AI 7–10 年延长"的指征也一起抹掉；3 次里有 2 次还把 60 岁绝经后患者推荐成 Tamoxifen，应该选 AI）。关键观察：三个模型、三种 wrapper（V4 Flash / Kimi K3 走 WorkBuddy 智能体、Grok 走 X.com 内置），全部在 3 灶 LVI 这一项上栽了——再次确认模型本身的差异 > 包装器的差异，而 Grok 用的还是最简单的 chat wrapper，照样最低分。参数规模≠临床图像可靠性：Kimi K3 是 2.8 万亿参数、Grok 是 X 内置实时联网+推理模型——照样栽在"读图"这一步。要做"智能体到底加多少分"的硬结论，仍需 V4 Flash / V4 Pro / Kimi K3 的网页版跑同一病例，本页等数据补齐。

Frequently asked questions

Why is the V4 Flash agent score (34) lower than V4 Pro agent (50)?

Two reasons. (1) Different case — Part 3's case has more decision points (LVI handling, bisphosphonate, AI duration) and no single-shot "gotcha" trap that V4 Pro happened to be good at. (2) The 10-item rubric here is stricter on the "specific guideline section" item, which no model in this series has passed yet. I will re-score V4 Pro on the Part 3 case once web runs are available, so the comparison becomes apples-to-apples.

Why did Kimi K3 (agent) score lower than DeepSeek V4 Flash (agent)?

Same wrapper, same case, same prompt, different model — and the result is different. That is the first concrete signal in this series that the model itself drives most of the variance, not the wrapper. Kimi K3 lost the LVI flag at the image-parsing step (it read the LVI's 0.05 / 0.06 / 0.2 cm numbers as three tiny invasive foci instead of lymphovascular invasion), so it never had a chance to apply the 7–10 year AI-extension rule. The downstream recommendations were still correct (chemo / RT / HER2 / CDK4/6 all correctly excluded), but the staging and the AI-duration were off. Note the scale: Kimi K3 is reported at ~2.8 trillion parameters, yet it made the same parsing error in all three runs — so for clinical-image tasks, a bigger model did not buy a more reliable read.

Why did Grok 4.5 fast (X.com) score lowest of the three Part-3 models?

Two reasons that stack. (1) Grok down-staged a confirmed pT1b invasive ductal carcinoma with 3-focus LVI to TisN0M0 / Stage 0 in all three runs — that is a more severe error than Kimi K3's off-by-one pT1a mistake, and it silently removes the LVI-driven AI extension from the decision. (2) Two of three Grok runs recommended Tamoxifen for a 60-year-old postmenopausal patient; only Run 3 picked the correct aromatase inhibitor. Both are wrapper-independent — Grok uses the simplest possible chat interface (X.com built-in), with no WorkBuddy-style system prompt or formatting scaffolding, yet the failure pattern is the same shape as Kimi K3's, just one notch worse. The fact that three different models, in three different wrappers, all failed the LVI read in 3/3 runs is the strongest evidence so far that the LVI read lives in the model, not the wrapper.

Why didn't you test the web version first, before writing?

I am running the tests in the order you supplied the data. The web runs for V4 Flash, V4 Pro, and Kimi K3 are still pending — they will land in this article (and re-rank the table) as soon as you send them. The 34 / 27 numbers are honest about what we have, not the final word.

Is the WorkBuddy agent just a system prompt, or is it doing more?

It's a system prompt plus a default "structured output" expectation (table format, stages of reasoning) plus tool-use scaffolding. In practice those three together change the model's behavior enough that "same model, different wrapper" comparisons routinely shift scores by 10–25 points in my experience. We will measure exactly how much in Part 3 once web runs are in.
