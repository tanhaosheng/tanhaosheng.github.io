📚 原创实测 / Hands-on Review series · 5-part plan, 3 published
What this series is. A planned 5-part hands-on review of free AI models on the same anonymized post-op breast cancer case (and one follow-up case). Every test uses the same prompt, the same scoring rubric, and the same reference standard (2026 CBCS / CSCO 2024 / NCCN 2025). Each part is signed, reproducible, and discloses the wrapper (chat interface, system prompt, mode) the model was used in. The point is not to crown a winner — it is to separate the model from the wrapper, the model from the parameter count, and the model from the marketing.

Methodology (same across all reviews)

  • One anonymized case at a time. Real post-op breast cancer pathology, scrubbed of patient identifiers, with the staging trap and the lymphovascular-invasion feature written into the case on purpose.
  • One prompt. An image of the case report + "Next therapy ?" (V3) or a 16-item structured question (V2). Same prompt, same image, every run.
  • Three independent runs per (model × wrapper) cell. No cherry-picking, no second-chance regeneration. If a model is confident, the three runs should be near-clones; if it is uncertain, the spread shows up in the median.
  • 10-item / 16-item rubric, 100 points. Items: correct staging, correct biology subtype, correct first-line therapy, correct therapy duration, correct chemo decision, correct radiation decision, correct anti-HER2 decision, correct bone protection, correct handling of LVI / high-risk features, and a hard "cite a specific guideline section" item. Correct + cited specific section = full points; correct but uncited = half; wrong = 0.
  • Reference standard. 2026 CBCS / CSCO 2024 / NCCN 2025 consensus. For each item, the "fully correct" answer is documented in the appendix.
  • Open data. The image, the prompt, the rubric, and the reference answer are all published in the Clinical LLM Benchmark data appendix. Anyone can reproduce the numbers.
One-line takeaway across V1–V3. Free AI models on a real clinical image give wildly different answers, and the model itself is the variable that matters most — the wrapper, the parameter count, and the "free vs paid" framing matter much less than the choice of model. The next two reviews (V4 web-direct, V5 final verdict) will pin that down with same-wrapper numbers.

Frequently asked questions

Why a 5-part series instead of one big comparison?

Because the interesting question is not "which model is best on one case" — it is why one model beats another. To answer that, you have to hold the case constant, then vary one variable at a time: model (V1, V2), wrapper (V3, V4), and finally a clinical decision rule (V5). One big table would obscure the cause; five focused reviews expose it.

Why is the same model scored on different cases across reviews?

V1 and V2 use a "Tis trap" case (a 0.2 cm microinvasive focus where the report's literal line says "TisN0M0 / Stage 0" but the correct stage is pT1miN0M0 IA — a classic transcription-error trap). V3 uses a different case that has no such trap but adds a multi-feature decision (correct staging + LVI handling + AI duration + bone protection). Different cases = different rubrics = different absolute scores, but within each review the ordering is fair and meaningful.

Can I submit my own run to the series?

Yes. The image, prompt, and rubric are public in the data appendix. Run any model, score yourself against the same 10 / 16 items, and email me the screenshot + score. I will add a community-runners section to the appendix and credit the runner. The point of the series is reproducibility, not exclusivity.

What is the "specific guideline section" rule, and why does it cost so many models points?

Each model's answer must cite a specific guideline section, table, or page number for the decision to count as fully correct. Citing a guideline by name (e.g., "NCCN 2025" or "CSCO 2024") without a specific location is half credit. Citing nothing is zero on that item. In V1–V3, every model in the series has lost the full 12 / 100 points on this item — across four model families and three wrappers. That is itself a finding: the "I don't cite sections" weakness is a model behavior, not a wrapper behavior.
