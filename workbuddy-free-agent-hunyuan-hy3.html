WorkBuddy 免费运行 Agent（混元 hy3）实测

作者 谭好升 · 副主任医师 / 医学博士 (Associate Chief Physician, MD/PhD) · 甲状腺乳腺外科 (Thyroid & Breast Surgery), 泰州市人民医院 (Taizhou People's Hospital)

🔥 头条 FEATURED 🆓 免费工具实测 🤖 AI Agent

如果你一直想用 Agent 自动化周报、写脚本、整理数据，但又卡在两件事上——「贵」与「要配环境」——这篇文章值得看完。作者 Tan Haosheng 把腾讯出品的 WorkBuddy（workbuddy.cn） 当作一台「可视化的 Agent 编排器」，内置可选用混元 hy3 这一限期免费、无额度上限的大模型；只要保证账户积分余额不为零（积分可通过完成任务或每日签到领取），就能持续跑 0 元/月的 Agent。

一、WorkBuddy 是什么？定位与官方表态

打开 https://workbuddy.cn，WorkBuddy 的官方自我介绍非常直接：

WorkBuddy 是腾讯出品的全场景 AI 办公工作台。说出要求、开始执行任务、交付完整成果。完美连接腾讯办公生态，你的办公好搭子。

对应到 S1——首页核心区域的画面：

从这一张就能看出三个关键信号：

  • 「全场景 AI 办公工作台」——不是 chat-only，而是「任务→执行→交付物」的流程型产品，这与主流办公场景贴合。
  • 「连接腾讯办公生态」——意味着可与微信、企业微信、腾讯文档、生态工具直接集成（这点对国内办公用户非常重要，避免"导出再导入"的痛点）。
  • 「下载 / 在线使用」并列——桌面客户端与 Web 版是同源产品，跨设备一致。这对需要"随时随地开 Agent"的用户很友好。

作者点评：定位清晰、与本土生态紧绑——这是 WorkBuddy 与 ChatGPT、Claude 等海外工具最大的差异点。如果你日常就在腾讯文档、企业微信里办公，Agent 跑出来的成果可以直接落进你已有的工作流，而不必在多个系统间来回搬运。

二、注册与登录：必须从"微信"开始

点击首页右上角登录后，弹出登录选择层——画面中央是硕大的「微信登录」按钮，下方才是「手机号 / 邮箱 / SSO」三个备选。

从这张图能读出三个事实：

  1. 没有「GitHub / Google 第三方登录」——这是国产产品典型的账号体系选择（手机号/微信/邮箱），对国内用户友好，但对海外读者不友好，意味着国际化路径要靠邮箱或 SSO。
  2. 「请先阅读并同意 用户服务协议 和 隐私政策」红色提示被放在顶部——合规意愿明确，但必须勾选后才能点同意，这一步不能跳过。这对个人用户多了一步动作，但对企业 IT 来说是好消息（便于审计）。
  3. SSO 选项存在——意味着企业版可以接入自有身份系统，未来若团队普及可以用企业账号管理。这一点普通用户暂时用不到，但对你判断"能否给团队部署"很关键。

作者点评：「微信登录为唯一主推」这个设定有两个推论：

  • ✅ 省事：国内用户 3 秒完成注册与登录，零摩擦。
  • ⚠️ 风险：账号本身是弱依赖手机号的"微信身份"，长期使用要注意不要把核心 Agent/任务都只挂在微信账号上——一旦微信端出现封号/解绑（极端情况），恢复成本会高于邮箱号。

因此建议：用自己可控的微信号登录即可，不推荐借用他人微信或临时小号——你后面跑出来的 Agent、积分、任务数据，都会跟这个身份走。

三、下载与安装：客户端与 Web 双轨

登录前，先回到 S1——你会注意到顶部主导航的下载按钮与首屏下半部并列出现的「立即下载」按钮。这两个入口通向同一个下载页（截图 S3）。

这一张主要说明三件事：

  1. 登录前后界面变化——右上角从「登录」变成了用户头像图标（绿色），说明登录态与下载态完全打通：你可以登录后再下载，也可以先下载再登录，两条路径独立都能完成。
  2. 「立即下载」与「在线使用」并存——意味着 WorkBuddy 没有强制要求安装客户端。对只是想"先试一把"的用户，直接点「在线使用」零安装试跑是更好的起点（避免系统兼容性问题）。
  3. 下载入口两处冗余（顶部"下载"按钮 + 屏内"立即下载"按钮）——这是常见的产品惯例，把决策路径最短化。

作者实测：登录后第一步

作者在 macOS 上登录后，WorkBuddy 主界面左上角有一个 "New Task" 按钮，点开就出现任务输入框——你既可以输入普通对话指令让 Agent 单次回复（类似 ChatGPT 的 chat-once 模式），也可以发布一个完整任务，让 Agent 在后台调用工具、产出可交付成果。这是一处产品上的简化：

  • 对话 = 单回合交互，输入完直接看结果；
  • 发布任务 = 把任务丢进 Agent 的"工作流"，它会自己拆步骤、调工具、产出文件并交付到任务里给你。

这两者的关键差别是：对话消耗的积分少，但只能一次性问答；发布任务消耗的积分多，但能跑多步、能自动交付产物。具体积分消耗速率（后续实测），等到作者实际跑完一项任务后再实测。

具体操作流：登录软件 → 左上角 New Task → 输入任务描述 → 按 Enter 触发对话 / 按「发布」按钮触发完整任务。下文 §六 会专门演示两种用法。

核心机制（作者归纳）

  1. "免费"是底层模型（混元 hy3）限期免费、额度无上限——不按 token 计费、不按调用次数封顶。
  2. 用户必须保证账户"积分余额 > 0"。余额清零 → 账户默认欠费状态 → 调用免费模型被立即中断。
  3. 积分领取有两条腿：
    • （A）做任务：WorkBuddy 内置的"赚积分"任务列表（具体奖励多少要看当时页面，因为活动随期变化——这一点必须在 APP 内查"成长计划 / 任务中心"才精确（作者后续截"任务中心"图）。
    • （B）每日签到：本期固定100 通用积分 / 天（已 S4 截图证实），无脑点击即领，连续签到还有周边奖励。
  4. 积分本身就是"通用积分"，意味着与具体模型（混元 hy3 还是别的）解耦——同一个积分池既可以调混元，也可以调 DeepSeek 或其他被 WorkBuddy 接入的模型。这是 WorkBuddy 设计上的合理点（不锁单一模型）。
  5. 当前期（5 期）会随本期结束而结束；下一期积分规则可能微调。要点：截图里的"5 期 7/29 结束"是 距今一天 的窗口期，决定要不要现在就上车。

作者点评

  • 它不是"无成本永动机"——必须每天手动签到保持积分进出平衡，与"打开水龙头就有水"不同。但既然签到只用 30 秒，养成习惯就不构成摩擦。
  • "清零即欠费"的策略≠ 苛刻，恰恰相反——它的好处是：你可以从前一天的具体余额数字判断"今天能不能跑这个 Agent"，而不是看着后台账单算 token。
  • 对独立开发者/小团队的实际意义：今天（7/28），你只要登录、点签到，就还有125.7 通用积分可以调用混元 hy3；理论上每天补 100 + 任务，长期保持 0 现金开销。
  • 风险：①"5 期 7/29 结束"之后，6 期规则可能改动（积分倍率、签到奖励都可能被调整），切勿把今天的数字当永久合同；②通用积分不是钱，不能跨平台/跨工具迁移，所以一旦脱钩 WorkBuddy，这些积分就归零。

作者实测建议

  1. 立刻做一次签到——而不是注册完就开始跑任务。哪怕剩余 100 积分，不够完成一个有意义的复杂任务（Agent 一次完整执行通常会扣 30–100 区间，需要实测（后续实测））。
  2. 每次跑 Agent 之前先看一下余额（在 S4 截图的"积分余额"那一行），预估能否承受一次完整调用；如果余额小于任务预算的 1/3，先签到/做任务。
  3. 关注本页右上角绿色横幅「Buddy 加油站 · X 期 · Y/M 结束」。本期结束后，下一期规则可能完全不一样——这是一切风险计算的源头。

五、为什么"混元 hy3"是关键？作者对模型层的判断

本文题目里写"免费运行 Agent（混元 hy3）"，是为了把读者最在意的两个词——「免费」和「选什么模型」——前置于标题。但这两件事在 WorkBuddy 里其实是两层：

  • WorkBuddy 层：编排 / 工具调用 / 结果交付 / 积分账本（也就是 §四 讲的内容）。
  • 模型层：实际"算"的引擎——可以选混元 hy3、也可以选其他模型（具体 WorkBuddy 内置了哪些、是否要开关，见 §六）。

为什么这篇文章盯的是「混元 hy3」：

  1. 混元是腾讯全栈自研的大模型，hy3 是其当下主流版本之一——意味着在中文场景、对接腾讯办公生态、与 WorkBuddy 的对齐性都更顺。
  2. 「限期免费 + 额度无上限」是个非常激进的策略——这是最值得立刻上车的窗口期。模型一旦开始按 token 计费，免费档往往变成"低速率 / 排队"或"附条件免费"——选择权还在你这边，但机会成本在变大。
  3. 对独立开发者 / 中小团队来说，免费=0 现金=没有"用着用着变成订阅"的隐性焦虑。

作者提醒：选模型不只是"看哪个免费"，还要看：① 该模型在 WorkBuddy 内是否做工具调用适配（不是所有模型都能挂工具）；② 长上下文支持；③ 中文表达稳定性；④ 是否会"幻觉式产出"。这些能力的实测数据，将在后续「跑实际任务」章节补全。

六、模型选择：怎么找到免费的 Hy3

很多读者最关心的第一步其实是："WorkBuddy 里到底在哪选模型？我能不能默认就用混元？"——本节用一张实图把这事钉死。

6.1 入口与默认

  • 入口：WorkBuddy 主界面右下角，输入框左下角的 Hy3 ^ 按钮（S5 红框位置）。点开就是模型下拉。
  • 当前默认选中：下拉顶部有两个开关层（Max mode / Auto），Auto 默认 ON；Auto 下面紧接 Hy3 · 限时免费 · 0.00x，右边带绿色对勾 ✓——这意味着作者登录后默认就是 Hy3 在跑，不需要任何额外点击。
  • 所以对零门槛用户来说：开软件 → 点 New Task → 输入 → 跑，模型就是 Hy3。

6.2 Hy3 的关键标识

  • 蓝色圆形 Hy3 logo。
  • 红色"限时免费"徽标——与 §四 提到的"5 期 7/29 结束"形成强对应：徽标既是免费的强证据，又点出该免费是有时间窗口的。
  • 价格倍率 0.00x——不是折扣，是真"零倍率"；其他模型都是 > 0（如 GLM-5.2 0.79x、GLM-5.1 0.79x、GLM-5v-Turbo 0.95x、MiniMax-M3 0.25x、Kimi-K3 1.62x、Kimi-K2.7-Code 0.57x……），意味着 Hy3 真的是不计费档。这一点对长任务尤其友好——其他模型按 token 倍率 × 时间长度很容易就吃掉大几十积分，Hy3 是 0 现金 + 0 积分倍率。

6.4 模型选择对话框的另外两个开关（顶置）

  • Max mode（顶部开关）：打开后会调用更强的推理模式，耗时会变长，对应积分消耗也变多（Hy3 仍是 0 现金，但积分倍率会变（后续实测））。
  • Auto（Auto 开关）：Auto = 由 WorkBuddy 路由决定模型；手动选 = 你锁定模型。两者各有适用场景——
    • 选 Auto：让平台"挑工具"，适合"任务描述模糊、我想先看 Agent 自己怎么干"的探索。
    • 选 Hy3（不勾 Auto）：锁定 Hy3，省钱、结果可控。
  • 底部还有一行 Configure custom models，意味着WorkBuddy 支持你自己加自定义模型（如本地 Ollama 或自部署模型），这对有私有化需求的企业用户非常关键——它意味着 WorkBuddy 不是"只能跑云端 SaaS 模型"的封闭产品。

6.5 其他 UI 元素（顺便记录，方便后续章节调用）

  • Working / Coding / Design：三个"Agent 模式"切换——这是 WorkBuddy 对Agent 性格/工作流的分档，决定调用的工具集合与系统提示词。同一模型在不同模式下行为会有差别。
  • 输入框提示语："What can I help you with today? @ to reference files, / to invoke skills"——意味着 WorkBuddy 沿用了主流 Agent IDE 的两条触发语法：@ 引用文件、/ 调用内置技能（skill）。这一点对"用户切换其他 AI IDE"非常友好，上手成本几乎为零。
  • 输入框下方：Select workspace（选工作区）+ Default permission（默认权限）——说明每一次任务可以绑定到不同工作区（= 不同项目上下文），且权限默认值可调整。
  • 左上角浮窗：活动通知「与好友分享 650 积分/人」——这条直接对应 §四 的"做任务赚积分"路径：在 S4 截图中那个"Buddy 加油站 5 期"本期活动的具体玩法之一就是邀请好友。点开应该能看到邀请链接（后续补全）。
  • 顶部右上角 Growth Rewards 按钮——直接跳到 S4 那张积分页。

6.6 作者决定

从这一张开始，本文所有"作者实测"段位（§七 §八 §九）默认都在 Hy3 下进行，原因有三：

  1. 0 倍率 → 积分消耗与时间成正比，与 token 无关 → 便于做"积分消耗速率"的真实记账。
  2. 与 WorkBuddy 同生态 → 中文输出与办公场景适配度最高。
  3. 这是作者本期剩余 125.7 积分最可能消费掉的模型——给读者一个贴近自身的实测样本。

八、目前能下的结论

基于已确认的六段事实（定位 + 微信登录 + 下载/客户端 + New Task 入口 + 积分机制 + 模型选择 UI），可以给出阶段性结论：

  • 注册门槛低：微信登录一步到位，国内用户 30 秒内可进入工作台。
  • 客户端 / Web 双轨：先不安装、用「在线使用」试一遍是合理起步路径；安装了则用左上角 New Task 触发对话 / 发布任务。
  • 「免费」的真含义已被截图钉死：底层模型限期免费 + 额度无上限（本期到 2026-07-29），账户必须维持积分余额 > 0，否则默认欠费停用免费模型。每日签到领 100 通用积分，作者当前余额 125.7。
  • 选混元 hy3 已经被产品 UI 默认锁定：Hy3 在模型列表里顶置、带"限时免费·0.00x"标识，登录后默认即 Hy3，不需要额外点击就能用免费模型。可选的其他模型（GLM-5.x、Kimi-K3 等）倍率从 0.25x 到 1.62x 不等——给"想跑得更专业"的用户留出口，给"只想省心"的用户留默认。

Caveat：以下核心指标仍未实测——① 跑一次对话任务实际扣多少积分；② 跑一次多步任务实际扣多少积分；③ Hy3 在多步工具调用下的产物质量与稳定性。不要基于本节就断言 WorkBuddy "无敌"——等剩下截图补全后结论可能改变。
