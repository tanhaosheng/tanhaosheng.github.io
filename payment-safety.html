<div class="container"><main>

    <p class="lead">移动支付给生活带来了极大便利，但也让不法分子有了可乘之机。本手册将手把手教您设置支付密码、限额、指纹锁等安全措施，让长辈既能享受便利，又能守住钱袋子。</p>

    <div class="danger-box"><strong>🚨 真实案例：</strong>2026年上半年，某市一位68岁老人因未设置支付限额，被骗子诱导扫描付款码，一次损失2万元。如果提前设置了单日限额500元，损失可以控制在极小范围内。</div>

    <h2>一、支付安全自检清单（先对照检查）</h2>

    <ul class="checklist">

        <li>支付密码不是生日、手机号或简单数字（如123456、000000）</li>

        <li>开启了指纹或面容支付（代替输入密码）</li>

        <li>设置了单日支付限额（建议500-1000元）</li>

        <li>关闭了"免密支付"功能</li>

        <li>开启了支付安全险（大部分免费）</li>

        <li>定期检查自动扣款项目，取消不需要的</li>

    </ul>

    <h2>二、支付宝安全设置（5步完成）</h2>

    <h3>第1步：设置强支付密码</h3>

    <div class="steps">

        <div class="step"><h4>打开支付宝 → 我的 → 右上角设置（齿轮图标）</h4><p>点击"账号与安全" → "支付密码" → "重置支付密码"。</p></div>

        <div class="step"><h4>设置6位数字密码</h4><p>避免使用生日、手机号、连续数字。建议选择一个家人都知道但外人猜不到的数字组合。</p></div>

    </div>

    <div class="safe-box"><strong>💡 密码建议：</strong>可以选择子女结婚年份+一个特殊数字，如"201508"。既好记，又不容易被猜到。</div>

    <h3>第2步：开启指纹/面容支付</h3>

    <p>进入<strong>设置 → 支付设置 → 生物支付</strong>，开启"指纹支付"或"面容支付"。这样付款时只需按指纹，不用输入密码，既方便又防止旁人偷看密码。</p>

    <h3>第3步：设置支付限额（最重要！）</h3>

    <p>进入<strong>设置 → 支付设置 → 支付限额</strong>：</p>

    <table><thead><tr><th>限额类型</th><th>建议设置</th><th>说明</th></tr></thead><tbody>

        <tr><td>单笔限额</td><td>500元</td><td>单次支付不能超过此金额</td></tr>

        <tr><td>单日限额</td><td>1000元</td><td>一天累计支付不能超过此金额</td></tr>

        <tr><td>单月限额</td><td>3000元</td><td>防止长期大额损失</td></tr>

    </tbody></table>

    <h3>第4步：关闭免密支付</h3>

    <p>进入<strong>设置 → 支付设置 → 免密支付/自动扣款</strong>，关闭所有不需要的免密支付项目。只保留确实需要的（如公交卡）。</p>

    <h3>第5步：开启安全险</h3>

    <p>在支付宝首页搜索"账户安全险"，大部分用户可以免费领取。一旦账户被盗，最高可赔付一定金额。</p>

    <h2>三、微信支付安全设置</h2>

    <p>打开微信 → <strong>我 → 服务 → 钱包 → 支付设置 → 修改支付密码</strong>。同样避免使用简单数字。</p>

    <p>在<strong>支付设置 → 指纹支付</strong>中开启。如果手机不支持指纹，可以开启"面容支付"。</p>

    <h3>设置转账到账时间（防骗关键！）</h3>

    <p>进入<strong>支付设置 → 转账到账时间</strong>，选择"2小时到账"或"24小时到账"。</p>

    <div class="safe-box"><strong>🛡️ 为什么这很重要：</strong>设置延迟到账后，如果不慎转给骗子，可以在到账前联系微信客服（95017）申请撤回。这是挽回损失的最后机会。</div>

    <h3>关闭自动扣费</h3>

    <p>进入<strong>支付设置 → 自动续费</strong>，检查并取消不需要的自动扣费项目。很多长辈不知不觉中订阅了各种服务，每月被自动扣款。</p>

    <h2>四、必须牢记的5条支付安全铁律</h2>

    <div class="danger-box">

        <ol style="padding-left:20px;margin:0;">

            <li style="margin-bottom:10px;"><strong>绝不向任何人透露支付密码</strong> —— 包括自称"客服"、"警察"的人</li>

            <li style="margin-bottom:10px;"><strong>绝不扫描陌生人发来的二维码</strong> —— 二维码可能直接扣款</li>

            <li style="margin-bottom:10px;"><strong>付款码只给收银员看，绝不截图发给别人</strong> —— 付款码等同于银行卡</li>

            <li style="margin-bottom:10px;"><strong>转账前必须电话确认对方身份</strong> —— 即使是"子女"要借钱，也要打电话核实</li>

            <li style="margin-bottom:10px;"><strong>发现异常立即冻结账户</strong> —— 拨打支付宝95188或微信95017</li>

        </ol>

    </div>
